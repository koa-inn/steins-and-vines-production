## Critical Anti-Patterns (do NOT repeat — each cost real time this session)

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|------------|
| `[skip ci]` blocks Pages publish | The gated-deploy CNAME commit ended in `[skip ci]`, so `deploy-production.yml` (push-triggered) never ran → prod frontend silently never published. Every frontend fix "looked broken" for hours. | blocking | FIXED in `fd49f2b`. Never put a skip-ci token in the production CNAME commit (or anywhere GitHub scans the HEAD commit message). |
| Cloudflare 403s curl | `steinsandvines.ca` is behind Cloudflare Bot Fight Mode → plain `curl` gets HTTP 403 (not a deploy failure). | advisory | Verify prod with a browser `-A` user-agent, or read the prod repo via `gh api repos/koa-inn/steins-and-vines-production/contents/<path>`. |
| Apps Script deploys manually | `apps-script/*.gs` is source-of-truth in the repo but the running code lives in the Apps Script editor — git push does NOT deploy it. | advisory | After editing a `.gs`, the user must paste it into Extensions → Apps Script and Deploy → Manage deployments → New version. |
| Recipe sheet positional write | `createRecipe` writes base columns positionally; inserting a column mid-sheet (e.g. pricing_mode at col F) misaligns the row. | advisory | Let the self-migrating helper add pricing_mode at the END; do not hand-insert columns mid-sheet. |
| Audit gate vs new CVEs | gated-deploy runs `npm audit --audit-level=high`; `package-lock.json` is gitignored so `npm install` resolves latest — a newly-published CVE fails a deploy that passed hours earlier. | advisory | Bump the offending dep range in `package.json` and re-run the workflow. |
