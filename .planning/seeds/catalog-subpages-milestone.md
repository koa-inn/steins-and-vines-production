# Catalog Subpages — Next Milestone Seed

Start a new milestone to restructure the ingredients catalog into dedicated subpages.

## Scope

1. **Shared template system** — Reusable page structure, sub-nav bar, cart integration, shared JS module base
2. **Grains subpage** — Grain + Malt Extract, unique hero/accent
3. **Yeast subpage** — Yeast + Yeast Nutrient, unique hero/accent
4. **Additives subpage** — Additive + Flavoring + Fruit + Oak, unique hero/accent
5. **Packaging subpage** — Bottle + Bag + closures, unique hero/accent
6. **Equipment subpage** — Fermenter + Hose/Tubing + uncategorized, unique hero/accent
7. **Sub-nav bar** — Horizontal category switcher on all ingredient pages (All | Hops | Grains | Yeast | Additives | Packaging | Equipment)
8. **Cross-category search** — Inline overlay with grouped results, deep-link to item on subpage
9. **Zoho subcategory tagging** — Ensure all items have Subcategory CF set, update snapshot pipeline
