**1. Add `initPromoBanner()` function to `js/modules/13-init.js`:**

Place the function definition BEFORE the `DOMContentLoaded` event listener. The function:

```javascript
function initPromoBanner() {
  // D-02: Skip if already dismissed via localStorage
  try {
    if (localStorage.getItem('sv-promo-banner-dismissed')) return;
  } catch (e) { /* localStorage unavailable — proceed */ }

  // Skip banner in kiosk mode (Pitfall 4 from RESEARCH.md)
  if (IS_KIOSK) return;

  // Fetch content/home.json (may already be cached by content loader)
  fetch('content/home.json')
    .then(function (r) { return r.ok ? r.json() : {}; })
    .then(function (data) {
      var config = data['promo-banner'];
      if (!config || !config.enabled) return;

      var el = document.getElementById('promo-banner');
      if (!el) return;

      // Populate banner content
      var tagEl = el.querySelector('.promo-banner-tag');
      var textEl = el.querySelector('.promo-banner-text');
      var ctaEl = el.querySelector('.promo-banner-cta');
      var dismissEl = el.querySelector('.promo-banner-dismiss');

      if (tagEl) tagEl.textContent = config.tag || '';
      if (textEl) textEl.innerHTML = config.text || '';
      if (ctaEl) {
        ctaEl.textContent = config.cta || '';
        ctaEl.href = config['cta-href'] || '#';
      }

      // Show banner by removing .hidden class (project convention)
      el.classList.remove('hidden');

      // Dismiss handler
      if (dismissEl) {
        dismissEl.addEventListener('click', function () {
          el.classList.add('hidden');
          try {
            localStorage.setItem('sv-promo-banner-dismissed', '1');
          } catch (e) { /* silently fail */ }
        });
      }
    })
    .catch(function () { /* silently fail — banner is non-critical */ });
}
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-12 | Tampering | content/home.json `promo-banner.text` field | accept | HTML is injected via innerHTML; however, content/home.json is a repo-controlled static file served from GitHub Pages (same origin). Not user-supplied. XSS risk only if repo is compromised, which is outside threat model scope. |
| T-08-13 | Spoofing | localStorage `sv-promo-banner-dismissed` | accept | A user could delete the localStorage key to see the banner again. This is expected behavior (D-02 explicitly accepts re-appearance after browser data clear). No security impact — banner is marketing content, not a security control. |
| T-08-14 | Denial of Service | initPromoBanner fetch failure | mitigate | Fetch wrapped in `.catch()` that silently fails; banner is non-critical content. Page functions normally without it. |
