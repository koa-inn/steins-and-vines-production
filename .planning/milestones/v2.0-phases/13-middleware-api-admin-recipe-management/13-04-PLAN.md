<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete admin Recipes tab with:
- Middleware recipe API (CRUD + availability checking)
- Admin panel Recipes tab (list view, detail/editor, ingredient autocomplete, availability indicators)
- Apps Script bug fixes (lock protection, cache key fix, error handling)
  </what-built>
  <how-to-verify>
**Pre-requisite: Deploy Apps Script**
1. Open the Google Sheet -> Extensions -> Apps Script
2. Replace the entire content of adminApi.gs with the updated version from `apps-script/adminApi.gs`
3. Click Deploy -> Manage deployments -> Edit the existing web app deployment -> Deploy
4. Wait for deployment to complete

**Then verify on staging:**

**Step 1: Open Recipes tab**
1. Visit `staging.steinsandvines.ca/admin.html`
2. Log in with Google OAuth
3. Click the "Recipes" tab (should appear after "Batches" in the tab bar)
4. EXPECTED: Empty state message "No recipes yet. Create your first recipe to get started."

**Step 2: Create a recipe**
1. Click "+ New Recipe"
2. Fill in: Name = "Test Pale Ale", Style = "American Pale Ale", Batch Size = 23, ABV = 5.2, IBU = 35
3. Set Locked Price = 175, Service Fee = 45, Materials Fee = 5
4. Leave Status as "Draft"
5. Click "+ Add Ingredient" -- an empty row appears
6. In the ingredient search box, type "malt" -- autocomplete dropdown should appear with matching ingredients from Zoho catalog, showing stock levels (e.g., "Pale Malt -- MALT-PALE-2ROW (45 kg available)")
7. Select an ingredient, enter Quantity = 4.5
8. Add 2-3 more ingredients (hops, yeast)
9. Click "Save Recipe"
10. EXPECTED: Toast "Recipe created." -- detail view reloads showing the saved recipe with availability indicators

**Step 3: Verify availability indicators**
1. On the recipe detail view, check the availability banner at the top
2. EXPECTED: Banner shows "All ingredients in stock" (green) if all ingredients have stock, or "N ingredient(s) low" (yellow), or "Cannot brew" (red) depending on actual stock
3. Each ingredient row should have a colored status dot (green/yellow/red)

**Step 4: Test activation guardrail**
1. Create a new recipe with no ingredients and no locked price
2. Try to change Status to "Active"
3. EXPECTED: Status reverts to "Draft", inline error "Set a locked price before activating this recipe." appears below the status dropdown
4. Add a locked price but keep 0 ingredients
5. Try to change Status to "Active" again
6. EXPECTED: Error "Add at least one ingredient before activating this recipe."

**Step 5: Test edit and filter**
1. Go back to list view
2. EXPECTED: The recipe you created appears in the table
3. Change the Status filter to "Draft" -- recipe should still appear
4. Change to "Active" -- recipe should NOT appear (it is draft)
5. Click the recipe row to open detail view -- edit the name, save
6. EXPECTED: Toast "Recipe saved." and name updates

**Step 6: Test delete**
1. Open a recipe detail view
2. Click "Delete Recipe"
3. EXPECTED: Browser confirm dialog "Delete recipe 'Test Pale Ale'? This cannot be undone."
4. Confirm deletion
5. EXPECTED: Toast "Recipe deleted." and returns to list view; recipe no longer in list
  </how-to-verify>
