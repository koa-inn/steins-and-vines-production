<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete kiosk recipe sale flow:
- Products/Recipes mode toggle in kiosk browse view
- Recipe cards showing name, style, ABV, locked price
- In-store/Take-out sale type selection prompt
- Mill grain toggle for take-out sales
- Availability checking with warning/block banners
- Cart population with recipe ingredients + fees
- Recipe sale endpoints (POST /api/kiosk/recipe-sale and /confirm)
- BEER_SALES_ENABLED feature gate (server-side 403)
- Redis mutex for concurrent sale prevention
- Batch auto-creation for in-store sales (fire-and-forget)
- Void-on-failure error handling
  </what-built>
  <how-to-verify>
Deploy to staging: `git push origin main`

**Pre-requisite:** BEER_SALES_ENABLED must be set to 'true' in Railway staging environment for the sale flow to work. If testing the feature gate, leave it as 'false' first and verify the 403, then set to 'true'.

1. **Visit** https://staging.steinsandvines.ca/admin.html?tab=kiosk
2. **Verify mode toggle:** You should see "Products" and "Recipes" toggle buttons above the product grid. Products mode is active by default.
3. **Switch to Recipes:** Tap "Recipes". The product grid should be replaced by a recipe card grid. If no active recipes exist, you should see "No active recipes" message.
4. **Recipe cards:** Each card should show the recipe name, style (e.g. "American Pale Ale"), ABV percentage, and locked price in the --barrel brown color.
5. **Tap a recipe card:** The grid should be replaced by the sale-type prompt showing the recipe name, "Ferment in Store" and "Take Out" buttons (64px tall), and an availability check result.
6. **Availability banner:** If stock is all good, no banner. If some ingredients low, yellow banner with "Proceed anyway" button. If out of stock, red banner blocking checkout.
7. **Select "Ferment in Store":** Button should get dark selected state. "Add to Cart" button appears with the locked price.
8. **Select "Take Out":** "Mill grain?" checkbox appears. Select it to add milling fee.
9. **Tap "Add to Cart":** Cart should populate with ingredient line items and applicable fees. Mode switches back to Products.
10. **Proceed to checkout:** The checkout flow should use the recipe-sale endpoint (you can verify in browser dev tools Network tab that it hits `/api/kiosk/recipe-sale` instead of `/api/kiosk/sale`).
11. **Back button:** From the sale-type prompt, tap the back arrow to return to recipe grid.
12. **Feature gate test:** If BEER_SALES_ENABLED is false in Railway, the terminal push should return 403 "Recipe sales are not enabled".
  </how-to-verify>
  <resume-signal>Type "approved" to confirm the recipe sale flow works correctly, or describe any issues found.</resume-signal>
