## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering | adminApi.gs updateBatch recipe_snapshot | mitigate | Validate recipe_snapshot is parseable JSON via `JSON.parse()` before writing to sheet — reject with error if invalid |
| T-16-02 | Tampering | brewpad.js recipe name/style XSS | mitigate | All recipe fields rendered via `escapeHTML()` before DOM insertion — same pattern as entire brewpad.js codebase |
| T-16-03 | Denial of Service | adminApi.gs recipe_snapshot cell size | mitigate | Trim snapshot to essential fields only (`{ name, style, abv, ibu, batch_size_l, ingredients: [{ item_id, item_name, quantity, unit }] }`) — stays well under 50K char cell limit |
| T-16-04 | Information Disclosure | /api/recipes endpoint | accept | Recipe list is staff-only (middleware requires x-api-key); no PII in recipe data |
</threat_model>
