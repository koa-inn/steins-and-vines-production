<objective>
Add a collapsible "Recipe" section to the BrewPad batch detail view. Batches with a recipe_snapshot show metadata and an editable ingredient table. Batches without a snapshot show "Attach Recipe" (search and link existing) and "Create Recipe" (slide-out form to create a new recipe and link it). All edits save to the batch's own snapshot only -- never modifying the master recipe record.

Per D-04, Edit Snapshot mode exposes ALL recipe fields for editing: name, style, ABV, IBU, batch_size_l, notes (as form inputs above the ingredient table) plus ingredient quantities (inline in the table). This covers the "we ran out of X, substituted Y" use case where staff need to update any field on the batch's recipe copy.

Purpose: Delivers D-04/D-05 (batch-local recipe editing of ALL fields), D-06 (expandable recipe section), and D-07 (all batches show recipe section including kit batches).
Output: Modified js/brewpad.js with Recipe section in renderBatchDetail + helper functions, modified css/brewpad.css with toggle, ingredient table, and edit-mode form styles.

function adminApiPost(action, payload) {
  if (!SHEETS_CONFIG.ADMIN_API_URL) return Promise.reject(new Error('Admin API not configured'));
  payload.action = action;
  payload.token = accessToken;
  return fetchWithRetry(SHEETS_CONFIG.ADMIN_API_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'text/plain' },
    body: JSON.stringify(payload)
  })
    .then(function (res) { return res.json(); })
    .then(function (data) {
      if (!data.ok) {
        if (isUnauthorizedError(data)) handleUnauthorized();
        throw new Error(data.message || data.error || 'API error');
      }
      return data;
    });
}
```

function readIngredientTableEdits(wrap, snapIngredients) {
  var inputs = wrap.querySelectorAll('.bp-recipe-qty');
  var result = [];
  Array.prototype.forEach.call(inputs, function (input) {
    var idx = parseInt(input.getAttribute('data-idx'), 10);
    if (!isNaN(idx) && snapIngredients && snapIngredients[idx]) {
      var copy = {};
      Object.keys(snapIngredients[idx]).forEach(function (k) { copy[k] = snapIngredients[idx][k]; });
      copy.quantity = parseFloat(input.value) || 0;
      result.push(copy);
    }
  });
  return result;
}
```
