## Spacing Scale

Admin panel uses named spacing tokens defined in `css/admin.css` lines 44–50. All values are multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| `--sp-1` | 4px | Icon gaps, tight inline padding, badge vertical padding |
| `--sp-2` | 8px | Compact element spacing, gap between toast items |
| `--sp-3` | 12px | **Pre-existing codebase token only** — row padding, header nav gaps, ingredient row vertical rhythm. Not part of this phase's spacing contract; new CSS classes in this phase do not introduce `--sp-3` usage. |
| `--sp-4` | 16px | Default element spacing, table cell padding, form group margin |
| `--sp-6` | 24px | Section padding, modal body padding, action bar padding |
| `--sp-8` | 32px | Layout gaps, heading margin |
| `--sp-12` | 48px | Major section breaks, page-level top/bottom padding |

**This phase's spacing contract:** {4, 8, 16, 24, 32, 48, 64}px — all multiples of 4. `--sp-3` (12px) is inherited from the existing admin CSS and appears in reused components; it is not declared as a new spacing value for this phase.

Exceptions:
- Review modal content width: `max-width: 800px` (overrides default modal 560px to accommodate 5-column ingredient table — per RESEARCH.md review modal HTML pattern)
- Touch target minimum: 44px (`min-height: 44px` on `.btn` and `.btn-secondary` per styles.css line 763/799)

## Color

Palette is defined as CSS custom properties in `css/styles.css` (lines 118–129) and `css/admin.css` (lines 4–41). This phase introduces no new colors — all values below are existing tokens.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `--cellar-canvas` | #e8e2ca | Page background, admin panel body |
| Secondary (30%) | `--cellar-raised` | #faf8f2 | Modal background, card surfaces, form inputs |
| Accent (10%) | `--barrel` / `--color-burgundy` | #77462d / #370e13 | **See reserved list below** |
| Success semantic | `--batch-success` | #3d7a40 | "Confirmed" match badge background and text |
| Warning semantic | `--batch-warning` | #b87a1a | "Low confidence" match badge, draft status badge |
| Destructive semantic | `--batch-danger` | #a83232 | "No match" badge, error toast left border, skip/remove actions |
| Muted | `--ink-muted` | #b8a898 | Skipped rows, placeholder text, disabled states |

Accent reserved for:
- "Import from BeerXML" button (`.btn` primary style — `--color-burgundy` #370e13 background)
- "Confirm Import" button in review modal (`.btn` primary style)
- Active Zoho match search dropdown focused state (`--ledger-focus` outline)
- Confidence badge border on high-confidence matches

Second semantic color (destructive) reserved for: skip row action, "No match" confidence indicator, error toast stripe.

**Review modal focal point:** The confidence badge column is the primary visual anchor. Its three-color status system (green "Matched" / amber "Review" / red "No match") draws the eye immediately to rows requiring staff action. The badge column must be visually prominent — badges are rendered as filled pill shapes, not text-only, so the color differential is immediately legible at a scan.

## Review Table Layout

The review table renders inside `.admin-modal-content` at `max-width: 800px`. Five columns:

| Column | Width | Content |
|--------|-------|---------|
| BeerXML Ingredient | ~25% | `beerxml_name` (escapeHTML applied), `beerxml_type` as sub-label |
| Original Amount | ~13% | `amount_display` (converted); `.beerxml-orig-value` sub-text shows raw BeerXML kg value |
| Unit | ~8% | `unit` (kg / g / pcs / L) |
| Zoho Match | ~35% | Autocomplete search input (reuses `.ing-search` pattern from existing ingredients table); shows matched item name + SKU below if matched |
| Status / Action | ~19% | Confidence badge (`.beerxml-match-high/low/none`) + skip toggle (`.beerxml-skip-btn`) |

Table header row: 11px uppercase labels, `--ink-tertiary`, `--ledger-emphasis` bottom border — matching `.admin-table thead th` exactly.
Row alternating background: matches `.admin-table tbody tr:nth-child(even)` — `rgba(119, 70, 45, 0.02)`.

## Interaction States

### "Import from BeerXML" Button
- Placement: alongside existing "New Recipe" button in Recipes tab header actions area
- Appearance: `.btn` (primary) with label "Import from BeerXML"
- Disabled: when `_recipesState.catalogLoaded === false` — show as `.btn` with `disabled` attribute, tooltip: "Loading ingredient catalog…"
- On click: programmatically triggers hidden `<input type="file" accept=".xml" id="beerxml-file-input">` click

### File Validation (before modal opens)
- Oversized file (>500KB): `showToast('BeerXML file is too large (max 500 KB). Please export a single recipe.', 'error')` — no modal opens
- Malformed XML (`parsererror` found): `showToast('The file contains invalid XML. Please re-export from your brewing software.', 'error')` — no modal opens
- No RECIPE element found: `showToast('No valid BeerXML recipe found in this file.', 'error')` — no modal opens
- Multiple recipes in file: `showToast('This file contains multiple recipes — importing the first one.', 'info')` — modal opens with first recipe only

### Review Modal
- Opens with `adminScaleIn` animation (already defined in `css/admin.css` line 759)
- Overlay: `rgba(44, 34, 24, 0.45)` backdrop
- Header: recipe name (escapeHTML applied) — "Review Import: {recipe name}"
- Sub-header metadata line: style, ABV, batch size in `--ink-secondary` at 13px
- Body: scrollable (`.admin-modal-body` overflow-y: auto), max-height constrainted by `.admin-modal-content` `max-height: 88vh`
- "Confirm Import" button: `.btn` — disabled until at least one non-skipped row has a valid Zoho match
- "Discard Import" button: `.btn-secondary` — `aria-label="Discard Import"` — closes modal, resets file input value to ''

### Per-Row Zoho Match Interaction
- Autocomplete search input: same `.ing-search` pattern as existing ingredient editor
- Selecting a match from dropdown: updates `zoho_match`, recalculates confidence badge to `high`, re-renders badge in place
- Skip toggle: text "Skip" (when not skipped) / "Restore" (when skipped); on skip, row gets `.beerxml-row-skipped`, opacity 0.45
- Skipped rows are excluded from confirmed ingredient list on Confirm Import

### Post-Confirm
- Modal closes
- Recipe form opens (blank) via `openRecipeDetail(null)`
- Form pre-populated with name, style, ABV, batch size, IBU, colour
- Status field locked to "draft" — staff cannot change to active until price is set (`canActivateRecipe()` guardrail)
- Ingredient rows rendered via `renderIngredientRows()` — same visual as manual entry
- Toast shown: `showToast('Recipe imported from BeerXML. Set a price and activate when ready.', 'success')`

## Accessibility Contract

- Review modal: `role="dialog"`, `aria-modal="true"`, `aria-labelledby="beerxml-modal-title"` (matches existing `.admin-modal` usage in RESEARCH.md)
- Focus management: on modal open, focus moves to modal close button; on modal close, focus returns to "Import from BeerXML" trigger button
- Confidence badges: add `aria-label` to each badge span — e.g., `aria-label="Match confidence: high"` — since color alone cannot convey status
- Skip button: `aria-label="Skip {ingredient name}"` / `aria-label="Restore {ingredient name}"`
- "Discard Import" button: `aria-label="Discard Import"` on the `.btn-secondary` element
- File input: `aria-label="Select BeerXML file"` (hidden input, associated with button trigger)
- "Confirm Import" disabled state: `disabled` attribute set on button element (not just `pointer-events: none`) so screen readers announce unavailability

## Security Contract

Source: RESEARCH.md Security Domain section.

| Rule | Implementation |
|------|---------------|
| Sanitize all BeerXML text | Wrap every `getTagText()` result in `escapeHTML()` before assigning to `.innerHTML` |
| Prefer textContent | Use `element.textContent = value` where no HTML rendering is needed (no escaping required) |
| File size gate before read | Check `file.size > 500 * 1024` before `FileReader.readAsText()` — never reads oversized files |
| Reset file input | Set `beerxmlFileInput.value = ''` in the `change` handler after reading — prevents same-file re-select silently failing |
