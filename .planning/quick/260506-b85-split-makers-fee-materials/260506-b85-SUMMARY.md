# Quick Plan 260506-b85: Split Maker's Fee into Maker's Fee ($45) + Materials Fee ($5 w/ PST) Summary

Split the $50 Maker's Fee into two Zoho service items: Maker's Fee ($45, GST only) and Materials Fee ($5, GST+PST) across server-side injection, frontend checkout display/tax, and kiosk POS.

## Task Summary

| Task | Name | Commit | Key Files |
|------|------|--------|-----------|
| 1 | Server-side: findMaterialsFeeItem + inject both fees | 4528824 | checkout-helpers.js, checkout.js, validateEnv.js, checkout.test.js |
| 2 | Frontend: fetch, display, and tax both fees | 55dde04 | 12-checkout.js, 11-cart.js |
| 3 | Kiosk: update hardcoded fee constants and sync both | 7e5b302 | kiosk.js + build artifacts (17 files) |

## Changes Made

### Task 1: Server-side
- Added `findMaterialsFeeItem()` in checkout-helpers.js matching SKU `MAT-FEE` or name "materials fee"
- Server-side checkout now strips client-submitted Materials Fee entries (prevents double-billing)
- Injects Materials Fee as a separate Zoho SO line item with promo discount support
- Graceful degradation: if MAT-FEE not found in catalog, logs warning but does NOT block checkout
- Added `MATERIALS_FEE_ITEM_ID` to optional env vars in validateEnv.js
- Added 10 unit tests for findMaterialsFeeItem

### Task 2: Frontend checkout
- Added `_materialsFeeItem` state variable, fetched alongside `_makersFeeItem` from /api/services
- Per-kit breakdown now shows 4 rows: Kit supplies, Maker's Fee, Materials Fee, Kit Total
- Kit supplies line subtracts BOTH fees from kit price
- Materials Fee tax calculated in all 5 tax blocks (render totals, dual-cart combined, dual-cart form summary, dual-cart charge, single-cart charge)
- Materials Fee included in promo savings calculation
- Cart sidebar (desktop + mobile drawer) shows combined fee total: "Includes fees ($50.00)"
- All fallback rates updated from $50 to $45 for Maker's Fee

### Task 3: Kiosk
- Split `MAKERS_FEE` constant from $50 to $45, added `MATERIALS_FEE = 5` and `MATERIALS_FEE_SKU`
- `kioskEffectiveRate()` now adds both fees to kit base price
- Added `kioskFindMaterialsFee()` helper
- Renamed `kioskSyncMakersFee` to `kioskSyncKitFees` -- syncs both fee items in cart
- Renamed `kioskIsMakersFee` to `kioskIsKitFee` -- matches both fee SKUs
- All 4 call sites updated
