<objective>
Split the single `customer_name` field into `customer_firstname` and `customer_lastname` across the entire BrewPad stack: Apps Script (data layer), Express middleware (kiosk auto-creation), and frontend (BrewPad + Admin batch forms and display).

Purpose: Enable proper first/last name storage for batch customers, supporting future features like personalized communications and proper name sorting.

Output: All new batches store first/last names separately while maintaining backward compatibility with existing single-name records.
</objective>
