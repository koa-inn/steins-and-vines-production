## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-90-29 | Tampering | client bundle price/tax | transfer | the server (Plan 90-02) ignores client rate/taxable and owns price + 12% tax; client mirror only for display, pinned by the parity test |
| T-90-30 | Tampering | catalog mutation for $0 can | mitigate | can line is a shallow copy with rate 0; test asserts the catalog product keeps its rate |
| T-90-31 | Integrity | stranded $0 can line / orphan | mitigate | paired removal (either key removes both); server also rejects orphan cans |
| T-90-32 | Information disclosure / XSS | modal and cart rows | mitigate | labels come from the constant table; any catalog name rendered via escapeHTML (existing cart convention) |
| T-90-33 | Repudiation | over-cap sale | accept | explicit operator tick recorded only in UI; the invoice shows the actual can count, which is the audit trail |
</threat_model>
