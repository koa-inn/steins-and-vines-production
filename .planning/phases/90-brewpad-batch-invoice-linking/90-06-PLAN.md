<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| middleware candidate JSON (Zoho-derived) -> BrewPad DOM | invoice numbers, customer and line-item names rendered |
| staff tap -> /api/batch/admin-proxy update_batch | the only write path for links and source |
| localStorage | device-local dismissals |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-90-24 | Information disclosure / XSS | candidate cards, warnings | mitigate | escapeHTML on every interpolated value (invoice number, names, line items, batch ids); no innerHTML from unescaped data |
| T-90-25 | Integrity | wrong links / identity overwrite | mitigate | linkBatchToInvoice sends only zoho_so_number (test asserts the key set); expectedVersion passed so concurrent edits conflict; reconcile recomputes cf_batch_status from the live set |
| T-90-26 | Integrity | unattended writes (D-10) | mitigate | writes only inside tap handlers; test asserts zero update_batch calls on render/Not this |
| T-90-27 | Tampering | source change from the UI | mitigate | Mark internal hidden for locked sources; server guards from Plan 90-01 are authoritative; invalid_source surfaced inline |
| T-90-28 | Tampering | localStorage dismissals | accept | only hides suggestions on one device; no data effect; corrupt values handled |
</threat_model>
