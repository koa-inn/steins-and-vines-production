## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Zoho contact data -> DOM | Search results (name/email/phone) rendered into the detail pane |
| BrewPad form -> middleware | Customer name/email/phone + batch id submitted from the browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29.1-06 | Tampering | XSS via search results / add-new echo | mitigate | escapeHTML on every rendered contact_name/email/phone and on confirm-sheet message text (showConfirmSheet uses textContent already) |
| T-29.1-07 | Tampering | concurrent edits to the same batch | mitigate | send expectedVersion (last_updated) in the POST; surface 409/version_conflict as an error toast prompting reload |
| T-29.1-08 | Information Disclosure | client-side logging | mitigate | no console.log of email/phone in the new flow; rely on server eventLog (plan 01) which omits PII |
| T-29.1-09 | Spoofing | unauthenticated middleware call | mitigate | every fetch sends x-api-key via mwApiKey() (existing pattern); server enforces (plan 01 T-29.1-01) |
| T-29.1-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages; build uses existing terser/cleancss pipeline. slopcheck N/A |
</threat_model>
