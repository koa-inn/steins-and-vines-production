<objective>
Build the middleware backend for batch customer reassignment: a customer search endpoint and a reassign endpoint that updates the batch first (source of truth), then optionally pushes the new customer to the linked Zoho SO/invoice. The reassign endpoint never rolls back the batch on a Zoho failure (D-05) and never calls Zoho when the batch has no linked order (D-03).

Purpose: Provides the server-authoritative contract the BrewPad UI (plan 02) consumes. Contact resolution, batch write, and Zoho propagation all happen server-side.
Output: Two new endpoints in `zoho-middleware/routes/pos.js` plus a new middleware test file. All middleware tests green.
</objective>
