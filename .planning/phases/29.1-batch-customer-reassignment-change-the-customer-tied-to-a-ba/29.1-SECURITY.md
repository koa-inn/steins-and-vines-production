## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| BrewPad client → middleware | Staff-authenticated browser POSTs customer data + batch id | Customer name/email/phone, batch id (untrusted input) |
| middleware → Zoho Books API | Customer create / SO+invoice customer_id mutation | Customer PII, order ids |
| middleware → Apps Script (Sheets) | Batch row write with optimistic lock | Batch customer fields, version token |
| Zoho contact data → DOM | Search results rendered into the detail pane | Contact name/email/phone (rendered) |
