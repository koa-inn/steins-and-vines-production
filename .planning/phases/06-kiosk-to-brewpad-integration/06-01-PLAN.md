<objective>
Modify the Apps Script backend to support pending batch creation from server-to-server calls and set up the Batches Google Sheet with new columns.

Purpose: The middleware needs an Apps Script endpoint that creates batches without requiring a fermentation schedule. This plan makes createBatch accept optional schedule_id/start_date (creating a "pending" batch when omitted) and adds a create_batch action to the doPost server-token branch so the middleware can call it using APPS_SCRIPT_SERVER_TOKEN.

Output: Modified adminApi.gs with pending batch support + Batches sheet with 3 new column headers.
</objective>
