**Step 1: Tune PHOTO_LABEL_REGIONS coordinates.**

View the downloaded can-photo.jpg and bottle-photo.jpg images. Based on the photo compositions, adjust the PHOTO_LABEL_REGIONS values in 14-labels.js so the label appears correctly positioned on each photo:

For the can photo (280x420 canvas):
- The label region should be centered on the visible front face of the can
- Typical can label placement: starts roughly 1/4 from top, centered horizontally
- Adjust `{ x, y, w, h }` so the warped label sits naturally on the can body

For the bottle photo (280x560 canvas):
- The label region should be centered on the bottle body (below the shoulder, above the punt)
- Typical wine bottle label placement: middle third of the bottle
- Adjust `{ x, y, w, h }` so the warped label sits naturally on the bottle body

Use the image dimensions and visual composition to determine realistic coordinates. The initial values from Plan 02 (`can: { x: 50, y: 100, w: 180, h: 200 }` and `bottle: { x: 60, y: 200, w: 160, h: 130 }`) are estimates that likely need adjustment.

**Step 2: Fix any ESLint errors.**

Run `npm run lint` and fix all errors. Common issues to watch for:
- Any accidental `let`/`const`/arrow functions (must be ES5)
- Missing semicolons
- Unused variables (old `LABEL_REGIONS` or `CANVAS_WIDTH` if not fully removed)
- `no-unused-vars` for any helper functions that are exported but not called internally

**Step 3: Fix any test failures.**

Run `npm test` (frontend tests). If any test references the old `#labels-canvas` ID or old exports like `_render` or `_handleTemplateSwitch`, update those tests to match the new API. The `tests/frontend/label-cards.test.js` tests `getTintClass` (04-label-cards.js), NOT 14-labels.js -- so no canvas test conflicts expected.

Run `cd zoho-middleware && npm test` (middleware tests). These should be unaffected by frontend-only changes.

**Step 4: Build.**

Run `npm run build` which executes:
1. `stamp:pages` -- updates `?v=` cache busters on custom-labels.html
2. `minify:css` -- generates `css/labels.min.css`
3. `minify:js` -- generates `js/modules/14-labels.min.js`
4. `concat:js` -- regenerates `js/main.js` and `js/main.min.js`

Verify build completes without errors.
