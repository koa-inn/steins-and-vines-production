<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BrewPad client → middleware | Authenticated reads/writes from a shared iPad PWA over `x-api-key` |
| Zoho/catalog data → DOM | Recipe names/statuses rendered into innerHTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-01 | Information disclosure | `renderRecipeList` innerHTML | mitigate | All dynamic recipe name/status/price values pass through `escapeHTML` (js/lib/utils.js) before innerHTML — prevents stored XSS via recipe name |
| T-37-02 | Spoofing | `GET /api/ingredients?include_internal=1` | mitigate | Catalog preload sends `x-api-key` via `getRecipesMwHeaders(true)` so Internal-Only items are gated server-side; list read (`/api/recipes`) is a non-sensitive public read, no key |
| T-37-03 | Denial of service | repeated tab visits re-fetching | accept | `_recipesDataLoaded`/`_recipesDataLoading` guard prevents refetch storms; manual refresh is explicit; low-value internal tool |
| T-37-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages added in this plan (reuses existing build/test deps); slopcheck N/A |
</threat_model>
