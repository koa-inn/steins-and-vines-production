<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BrewPad client → middleware delete | Destructive DELETE from a shared iPad over `x-api-key` |
| Shared-device operator → destructive action | Any staff member on the shared iPad can trigger delete |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-08 | Repudiation / accidental destruction | recipe delete on shared iPad | mitigate | Delete routes through `showConfirmSheet` with the danger variant + irreversible-warning copy (D-04) — no one-tap delete; operator must explicitly confirm |
| T-37-09 | Tampering | DELETE write path | mitigate | DELETE sends `x-api-key` via `getRecipesMwHeaders(true)`; on `!data.ok` or network reject, an error toast is shown and the list is NOT optimistically mutated (no silent partial state) |
| T-37-10 | Information disclosure | confirm-sheet message innerHTML | mitigate | Recipe name in the confirm message is rendered via the existing escaped path / showConfirmSheet text handling (no raw innerHTML of unescaped name) |
| T-37-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages; `npm run build`/`npm test`/`npm run lint` use existing committed dev deps only |
</threat_model>
