## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Self-confirming mocks | Code under test and its unit mocks share an invented external-response key (`balance`); tests pass green while prod fails closed (F1) | blocking | Derive mock payloads from a captured real Apps Script/Zoho/Helcim response or a contract test — not from the code being tested |
| Re-charging during an unresolved orphan path | F2 shows auto-confirm can miss a live approval; re-running terminal steps risks another orphaned charge on the owner's card | blocking | No live re-charge until F2 has a logged sale->poll repro; verify Zoho booking immediately after any UAT charge |
| Untagged custom line = Zoho default-tax | Custom lines have no backing Zoho item, so exempt lines need an explicit zero-rate `tax_id`/exemption or Zoho applies org default GST (F3) | advisory | Fixed via `ZOHO_TAX_ZERO_ID` on `taxable===false` custom lines (97e8124); confirm-path regression asserts `tax_total:0` |
