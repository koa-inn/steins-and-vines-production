<objective>
Add a CI artifact-drift check (D-10): rebuild and fail CI if the tracked minified/concatenated artifacts that GitHub Pages actually serves diverge from a fresh build of their source — scoped to deterministic minify output so the Date.now() cache-buster stamp does not cause false positives. The audit confirmed current artifacts reproduce byte-for-byte, so this is drift-prevention.

Purpose: Today CI never runs `npm run build` or verifies tracked artifacts, so a tested, merged money-path/kiosk fix can silently never execute in the browser behind a stale bundle (tests stay green).
Output: A drift-check script + a CI step that gates on it.
</objective>
