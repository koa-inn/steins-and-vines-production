Bring kiosk pos.js sale + confirm up to the checkout.js bar using the shared lib/money-path.js (D-12): atomic idempotency (required key, 409 on contention, deterministic Helcim key) and a confirm handler that PROPAGATES payment-recording failures so the outer void fires — closing the double-charge and the "money taken but unrecorded, staff see success" classes.
