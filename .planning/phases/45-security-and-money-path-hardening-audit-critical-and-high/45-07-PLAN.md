<objective>
Close the gift-card split-tender underpayment hole (D-12) and lay the orphan-defense interface (D-13): validate the applied gift amount against the certificate's real server-side balance before charging the reduced terminal amount, set needs_manual_review on a redeem failure, and on a terminal timeout persist a pending-charge context (keyed by reference_number) that the reconciliation backstop (45-08) consumes.

Output: Balance-validated split-tender + needs_manual_review on redeem failure + a persisted pending-charge interface + tests written FIRST.

INTERFACE NOTE: This plan DEFINES the pending-charge cache key (KIOSK_PENDING_CHARGE_PREFIX in lib/constants.js) and the persisted record shape. 45-08 consumes it.
