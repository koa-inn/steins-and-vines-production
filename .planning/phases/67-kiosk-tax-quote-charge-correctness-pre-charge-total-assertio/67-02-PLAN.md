<objective>
Land the frontend half of the kiosk quote≠charge fix (deploys AFTER 67-01 middleware is live). Three coordinated changes in `js/kiosk-core.js`:

1. Remove the client silent 5% tax fallback and the inconsistent `|| 0` — a missing/unparseable `tax_percentage` becomes a data error: flag the item by name and block checkout (fail-closed), never guess.
2. Send the kiosk's displayed totals (`client_grand_total`, `client_tax_total`) with the sale POST so the server-side pre-charge assertion (from 67-01) can catch any divergence.
3. Force-refresh the in-memory catalog at the cart-lifecycle points the New Sale button misses, so a parked-overnight kiosk cannot quote from a stale snapshot.

Purpose: the client stops silently under-quoting tax, and every real sale now carries a displayed total the server asserts against.
Output: hardened `js/kiosk-core.js` + rebuilt min artifact + frontend regression tests.
</objective>
