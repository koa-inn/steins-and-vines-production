<objective>
Add an inline Delete button to the BrewPad dashboard "Needs Scheduling" pending rows (D-02) so staff can delete duplicate pending batches from BrewPad with a confirmation step, instead of editing the Google Sheet by hand. The BrewPad batch-list cards under the Pending filter intentionally stay clean tap-targets with NO inline Delete (D-03) to avoid fat-finger mobile deletes.

Purpose: Mirror the admin inline-delete affordance (Plan 27.1-01) on the BrewPad surface where pending batches also appear, reusing the existing fully-wired `delete_batch` action and the BrewPad bottom-sheet confirm pattern (D-11). No backend changes (D-06).

Output: Modified `js/brewpad.js` (source) + rebuilt `js/brewpad.min.js` / `js/main.min.js`.
</objective>
