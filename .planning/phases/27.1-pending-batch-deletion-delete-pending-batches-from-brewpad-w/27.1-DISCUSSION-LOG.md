## Delete button placement

| Option | Description | Selected |
|--------|-------------|----------|
| Both lists (Recommended) | Inline Delete beside the Activate buttons on admin list pending rows AND on BrewPad's "Needs Scheduling" dashboard rows. Detail views keep their existing buttons. | ✓ |
| Admin list only | Inline Delete only beside the admin Batches tab Activate buttons; BrewPad users go through the detail pane's existing Delete. | |
| BrewPad only | Inline Delete only on BrewPad's "Needs Scheduling" rows; admin users use the detail modal's existing Delete. | |

**Follow-up:** Should BrewPad batch list cards (Pending filter) get an inline Delete too?

| Option | Description | Selected |
|--------|-------------|----------|
| No — detail is enough (Recommended) | Cards stay clean tap-targets opening the detail pane (which already has Delete). Avoids accidental fat-finger deletes on mobile. | ✓ |
| Yes — cards too | Inline Delete on pending batch cards as well. | |

**User's choice:** Both lists; no inline delete on BrewPad cards.

## Status restriction policy

| Option | Description | Selected |
|--------|-------------|----------|
| Inline pending-only, detail any (Recommended) | New inline buttons appear only on pending rows (UI-gated). Existing detail-view Delete keeps working for any status — no backend change. | ✓ |
| Server guard: pending-only everywhere | deleteBatch rejects non-pending server-side; would break existing detail-modal Delete for active/complete batches. | |
| Server guard + force flag | deleteBatch rejects non-pending unless an explicit allow_any flag; detail views pass the flag. | |

**User's choice:** Inline pending-only, detail any.
