## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-92-29 | Information disclosure | customer history persisting across customers | mitigate | _kioskPsCustomerClear hook runs on every kioskPastSalesClear (view switch, lock, back); generation counter drops late search/history responses; tests (D-11) |
| T-92-30 | Information disclosure | contact email/phone on screen | mitigate | Dropdown renders contact_name only (discretion choice); test asserts email/phone absent |
| T-92-31 | Tampering (XSS) | contact rows, history rows | mitigate | escapeHTML on every dynamic string/attribute; XSS payload test |
| T-92-32 | Information disclosure | walk-in contact history | mitigate | Server enforces walk_in (92-04); client shows the D-09 message and renders nothing |
| T-92-33 | Denial of service | search keystroke spam | mitigate | 300 ms debounce + 2-char minimum (server also rejects < 2 chars) |
