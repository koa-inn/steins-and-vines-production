## Typography

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 16px (1rem) | 400 | 1.6 | `--font-body` | General page text |
| Label / small | 10px (0.625rem) | 700 | 1.2 | `--font-body` | `.brand` on wine label cards |
| Producer line | 9.6px (0.6rem) | 400 | 1.2 | `--font-body` | All producer displays: `.producer` on label cards, `.product-producer` on default cards, `.cart-sidebar-item-producer` in cart sidebar |

Typography hierarchy for kit cards (top to bottom):
1. `.producer` — 0.6rem, weight 400, uppercase, muted color, wide letter-spacing (smallest — "who made it")
2. `.brand` — 0.625rem, weight 700, uppercase, brown/gold color (identity)
3. `.wine-name` / `.beer-name` / `h4` — 1rem–1.6rem (what you're buying)

Rationale: weight 400 for producer reinforces the hierarchy — bold 700 is reserved for brand identity, regular 400 signals contextual metadata. A single 0.6rem size across all producer contexts is perceptibly subordinate to `.brand` (0.625rem) while remaining legible.

Source: CONTEXT.md D-02; RESEARCH.md CSS code examples; `css/styles.css` lines 4352–4358, 4520.

## Component Inventory

### New: `.producer` element (label cards)

- Element type: `<div>`
- Class: `producer`
- Parent: `.label-body` (wine) or `.label-beer` inner body (beer)
- DOM position: appended to body BEFORE `.brand` element
- Conditional: only rendered when `product.manufacturer` is truthy (D-11)
- Content: `product.manufacturer` via `.textContent` (never innerHTML — XSS safety)

### New: `.product-producer` element (default product cards)

- Element type: `<div>`
- Class: `product-producer`
- Parent: `.product-card-header`
- DOM position: before `.product-brand` element
- Conditional: only rendered when `product.manufacturer` is truthy

### New: `.cart-sidebar-item-producer` element

- Element type: `<div>`
- Class: `cart-sidebar-item-producer`
- Parent: `.cart-sidebar-item-info`
- DOM position: inserted before `.cart-sidebar-item-brand` (or null if brand absent)
- Conditional: only rendered when `item.manufacturer` is truthy

### New: Producer filter (`#filter-manufacturer`)

- Pattern: identical to existing `#filter-brand` — uses `buildFilterRow('filter-manufacturer', 'manufacturer', 'Producer:')`
- HTML container: `<div class="catalog-filter-row" id="filter-manufacturer"></div>` in `products.html`
- Position in HTML: between `#filter-brand` and `#filter-subcategory`
- Label: "Producer:" (matches "Brand:" label pattern)
- Active state: identical to brand filter — `var(--color-green)` background, `var(--color-cream)` text

### Inline compact format (checkout table, kiosk list/grid, kiosk cart line)

- Format: `"Producer — Name"` using em dash (`—`, U+2014)
- Separator choice: em dash — matches existing site typography patterns
- Fallback: if `item.manufacturer` is falsy, render `item.name` alone (no separator, no empty prefix) per D-12
- Rendered via `.textContent` in text-only contexts; via `escapeHTML()` in template string / innerHTML contexts

### Admin kits table

- New column: "Producer" header (`<th>Producer</th>`) inserted before existing "Brand" column in `admin.html`
- Cell content: `zohoEntry.manufacturer || ''` — sourced from `zohoKitMap` (Zoho API side), NOT from `kitsData` (Sheets side)
- Empty string renders as blank cell (no placeholder text)

Source: CONTEXT.md D-03, D-08, D-09; RESEARCH.md Patterns 3–6.

## Interaction Contract

### Producer filter behavior

- Clicking a producer button filters the catalog to show only kits from that producer
- Multiple producer selections are OR'd (same as brand filter: any selected producer matches)
- Active button state: `var(--color-green)` fill, `var(--color-cream)` text
- Inactive button state: `var(--color-cream)` fill, `var(--color-brown)` text border
- Clearing producer filter: click active button again (toggles off) — identical to brand filter
- URL param sync: follows existing `buildFilterRow` behavior (adds `?manufacturer=RJS` to URL on selection)

### Fallback / missing data behavior

- If `product.manufacturer` is empty string or falsy: `.producer` DOM element is NOT created
- Card renders identically to current state (brand and name still show if present)
- No "Unknown producer" placeholder rendered
- No visual indicator that manufacturer is missing

### XSS safety contract

- All `.producer` content rendered via `.textContent` — never via `innerHTML`
- Inline compact format uses `escapeHTML(item.manufacturer)` when interpolated into HTML template strings (kiosk.js uses template strings)
- In vanilla DOM contexts (06-featured.js, 07-catalog-kits.js, 11-cart.js, 12-checkout.js): `.textContent` is sufficient

Source: RESEARCH.md Security Domain; Anti-Patterns section.

## CSS Specification

New rules to add to `css/styles.css`, grouped near existing `.label-wine .brand` and `.label-beer .brand` declarations:

```css
/* Producer line — wine label cards */
.label-wine .producer {
  font-family: var(--font-body);
  font-size: 0.6rem;
  font-weight: 400;
  text-transform: uppercase;
  letter-spacing: 0.15em;
  color: var(--color-muted);
  margin-bottom: 0.25rem;
}

/* Producer line — beer label cards */
.label-beer .producer {
  font-family: var(--font-body);
  font-size: 0.6rem;
  font-weight: 400;
  text-transform: uppercase;
  letter-spacing: 0.15em;
  color: var(--color-muted);
  margin-bottom: 0.25rem;
}

/* Producer line — default product cards */
.product-producer {
  font-size: 0.6rem;
  font-weight: 400;
  text-transform: uppercase;
  letter-spacing: 0.08em;
  color: var(--color-muted);
  margin-bottom: 0.1rem;
}

/* Producer line — cart sidebar */
.cart-sidebar-item-producer {
  font-size: 0.6rem;
  font-weight: 400;
  color: var(--color-muted);
  margin-bottom: 0;
}
```

Rationale: A single `0.6rem` size is used across all producer contexts. At `0.6rem`, producer is perceptibly subordinate to `.brand` (`0.625rem` on wine, `0.6875rem` on beer) without being illegible. Weight `400` (regular) signals contextual metadata, reserving weight `700` for brand identity. Margin `0.25rem` (4px) on label cards matches the existing `.brand` margin-bottom on beer cards and sits on the 4px grid. No margin on the cart sidebar element lets the brand element's own spacing handle the gap.

Source: RESEARCH.md CSS code examples; `css/styles.css` lines 4352, 4520.
