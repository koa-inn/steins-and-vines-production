## Spacing Scale

The project uses `rem`-based spacing with a root font-size of `16px`, mapping cleanly to an 8-point grid.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (0.25rem) | Icon gaps, star letter-spacing |
| sm | 8px (0.5rem) | Inline element spacing |
| md | 16px (1rem) | Default paragraph, card element gaps |
| lg | 24px (1.5rem) | Card padding, testimonials-grid gap |
| xl | 32px (2rem) | Section vertical padding (landing copy sections) |
| 2xl | 48px (3rem) | Section padding (`.intro`, `.content` pattern) |
| 3xl | 64px (4rem) | Not used in this phase |

Exceptions: none for this phase.

Source: existing `.intro { padding: 3rem 0 }`, `.testimonial-card { padding: 1.5rem }`, RESEARCH.md Pattern 4.

## Component Inventory

### 1. Testimonial Section (NEW)

Location: `index.html`, after `.why-wine` section, before the next `section-icon` divider.

**Section HTML structure:**
```html
<section class="testimonials">
  <div class="container">
    <h2>What Our Customers Say</h2>
    <div class="testimonials-grid" id="testimonials-grid">
      <!-- Populated by loadTestimonials() from content/reviews.json -->
    </div>
  </div>
</section>
```

**Card HTML structure (rendered by JS):**
```html
<div class="testimonial-card">
  <div class="testimonial-stars" aria-label="{N} out of 5 stars">
    &#9733;&#9733;&#9733;&#9733;&#9733;
  </div>
  <blockquote class="testimonial-text">
    <p>{escapeHTML(review.text)}</p>
    <footer class="testimonial-name">— {escapeHTML(review.name)}</footer>
  </blockquote>
  <a href="{escapeHTML(review.url)}" class="testimonial-link"
     target="_blank" rel="noopener">View on Google</a>
</div>
```

Semantic note: `<blockquote>` with `<footer>` for attribution (not `<cite>`) — avoids semantic misuse of `<cite>` for person names. Source: RESEARCH.md Pitfall 6.

**Grid layout:**
- Desktop (> 768px): `display: grid; grid-template-columns: repeat(3, 1fr); gap: 1.5rem`
- Mobile (≤ 768px): `grid-template-columns: 1fr` (single column stack)

**CSS classes (all new, append to `styles.css`):**

| Class | Property Declarations |
|-------|----------------------|
| `.testimonials` | `padding: 3rem 0; text-align: center` |
| `.testimonials h2` | `color: var(--color-green); margin-bottom: 2rem` |
| `.testimonials-grid` | `display: grid; grid-template-columns: repeat(3, 1fr); gap: 1.5rem; margin-top: 1rem` |
| `.testimonial-card` | `background: white; border: 1px solid rgba(74,111,75,0.2); border-radius: var(--radius-sm); padding: 1.5rem; text-align: left; display: flex; flex-direction: column; gap: 0.75rem; box-shadow: 0 2px 8px rgba(0,0,0,0.08)` |
| `.testimonial-stars` | `color: var(--color-brown); font-size: 1.1rem; letter-spacing: 0.05em` |
| `.testimonial-text` | `font-style: italic; font-size: 0.95rem; line-height: 1.6; color: var(--color-text); flex: 1; margin: 0` |

## Interaction Contracts

### Testimonial Cards

| Interaction | Behaviour |
|-------------|-----------|
| Card hover | No hover state required — cards are static display only |
| "View on Google" link | Opens Google Business Profile reviews page in new tab (`target="_blank" rel="noopener"`) |
| Keyboard focus | `outline: 2px solid var(--color-burgundy); outline-offset: 2px` via existing `:focus-visible` rule — no new CSS needed |
| Star rendering | Unicode `&#9733;` (filled) characters only — all 5 stars filled for 5-star reviews. `aria-label="{N} out of 5 stars"` on the wrapper div |
| Mobile stacking | Single-column grid via `@media (max-width: 768px)` |

### Landing Page CTA Anchor Link

| Interaction | Behaviour |
|-------------|-----------|
| "Browse Wine Kits" click | Smooth scroll to `#product-catalog` anchor on same page (CSS `scroll-behavior: smooth` already set on `html`) |

### Facility Photos

| Interaction | Behaviour |
|-------------|-----------|
| Image load | `loading="lazy"` deferred until near viewport. `width`/`height` attributes required to prevent layout shift |
| No lightbox | Photos are decorative content — no click-to-enlarge interaction |

## Data Contract

### `content/reviews.json` (NEW FILE)

```json
{
  "reviews": [
    {
      "name": "{First name Last initial}",
      "rating": 5,
      "text": "{Review quote text}",
      "url": "https://g.page/r/{profile-id}/review"
    }
  ]
}
```

Field constraints:
- `name`: string, reviewer first name + last initial (e.g. "Sarah M.") — applied through `escapeHTML()`
- `rating`: integer 1–5 — only value used is number of filled stars
- `text`: string, review quote — applied through `escapeHTML()`
- `url`: string, Google Business Profile reviews URL — validated visually before publish; must be `maps.google.com` or `g.page` domain

Source: CONTEXT.md D-06/D-07/D-09, RESEARCH.md Pattern 2 and Security Domain.

### Image File Naming

Facility photos land in `images/facility/` (new subdirectory). Naming convention: `facility-01.jpg`, `facility-02.jpg`, etc. Exact filenames TBD when user provides photos.

## Accessibility Constraints

| Constraint | Requirement |
|-----------|-------------|
| Star ratings | `aria-label="{N} out of 5 stars"` on `.testimonial-stars` wrapper — Unicode stars are not reliably announced by screen readers |
| External links | `rel="noopener"` on all `target="_blank"` links — prevents tab-nabbing |
| Image alt text | Every facility photo `<img>` must have descriptive alt text including business name and Squamish location reference (e.g. `alt="Steins &amp; Vines wine fermentation facility in Squamish, BC"`) |
| Image dimensions | Explicit `width` and `height` on every `<img>` — prevents CLS, required for Core Web Vitals |
| Focus visible | Inherited from existing `*:focus-visible { outline: 2px solid var(--color-burgundy) }` — no new rules needed |

Source: RESEARCH.md Pitfall 4, Security Domain.

## Build Requirements

After any change to CSS or JS modules, the executor must run:

```bash
npm run build
```

This regenerates `styles.min.css` (from `styles.css`) and `main.min.js` (from `js/modules/*.js`). Pages load the minified files. Skipping this step means new styles and JS are invisible in the browser.

Source: RESEARCH.md Pitfall 2, CLAUDE.md.
