| Token | Value | Usage |

| sm | 8px | Pill padding (vertical), filter bar gap, card inner gap |

Note: Sub-nav pill padding uses `8px vertical / 16px horizontal` — conforming to sm/md tokens. Previous draft had non-conforming `6px / 14px` values; corrected in this revision.

## Typography

All sizes are from the existing established design system. No new type sizes are introduced in this phase.

| Role | Size | Weight | Line Height | Font Family | Usage |
|------|------|--------|-------------|-------------|-------|
| Hero heading | clamp(1.625rem, 4vw+1rem, 3rem) | 700 | 1.2 | Playfair Display | Subpage hero `<h1>` (CAT-01 through CAT-05) |
| Body / description | 16px (1rem) | 400 | 1.6 | Lato | Hero description text, card body text |
| Label / UI control | 13px (0.8125rem) | 700 | 1 | Lato | Sub-nav pill labels |
| Small / meta | 14px (0.875rem) | 400 or 700 | 1.5 | Lato | Card price, stock indicator, filter pill labels |

Font weights in use: **400** (regular) and **700** (bold). Weight 600 appears on h2/h3 site-wide but is not introduced new in this phase.

Typography note (13px vs 14px): These sizes are 1px apart and are visually distinct in rendered context because they serve different roles with different weights. Sub-nav pill labels (13px/700) are bold and uppercase-adjacent in a compact pill container; card meta text (14px/400 or 700) is regular-weight in an open card layout. The weight contrast (bold pill vs regular meta) reinforces the size difference and prevents visual confusion. Both sizes are carried forward from existing `css/catalog-subpage.css` — no new sizes introduced.

Source: `css/styles.css` lines 142-227, `css/catalog-subpage.css` lines 34-55.

## Component Inventory

### New: Ingredient Sub-nav Bar

**Element:** `<nav class="ingredient-subnav" aria-label="Ingredient categories">`

**Behavior:**
- Sticky, sits immediately below the site header
- `position: sticky; top: var(--header-height, 80px); z-index: 190`
- Header is `z-index: 200` — sub-nav must be lower to prevent dropdown overlap
- `--header-height` is set dynamically by `js/modules/13-init.js` via ResizeObserver; 80px fallback covers initial render flash

**Mobile behavior (Claude's discretion — resolved):** Horizontal scroll with hidden scrollbar. Single row, no wrapping. Rationale: two-row wrap pushes page content down and conflicts with the sticky behavior; horizontal scroll is the standard mobile pattern for category tabs (e.g., Amazon, YouTube). `overflow-x: auto; scrollbar-width: none; -webkit-overflow-scrolling: touch`.

**Pills:** 7 anchors — All | Hops | Grains | Yeast | Additives | Packaging | Equipment
- Each: `<a class="subnav-pill" data-subnav="{slug}">` — `<a>` not `<button>` because these are page navigations
- `padding: 8px 16px; min-height: 36px; border-radius: 20px`
- Border: `1px solid var(--color-green)` inactive; filled `var(--color-green)` active
- Text: `var(--color-green)` inactive; `var(--color-cream)` active
- Transition: `background 0.15s, color 0.15s`
- Focus: `outline: 2px solid var(--color-green); outline-offset: 2px`

**Active state:** CSS-only via `body[data-page="{slug}"] .subnav-pill[data-subnav="{slug}"]`. No JavaScript. (Source: RESEARCH.md Pattern 3, `body[data-page]` CSS selector.)

**Search placeholder:**
- `<button type="button" class="subnav-search-btn" aria-label="Search ingredients (coming soon)" disabled>`
- `cursor: not-allowed; opacity: 0.5` — visually signals non-functional state
- Renders at right end of sub-nav, `margin-left: auto`
- SVG: 18x18px, `viewBox="0 0 24 24"`, magnifying glass icon, `stroke="currentColor" stroke-width="2"`
- No click handler in Phase 22. Phase 23 wires it up.

### Updated: Products Dropdown

**Element:** `.nav-dropdown-menu` (`<ul>`)

**New structure:** Two groups separated by a divider `<li>`:
1. Group 1 (existing): Ferment in Store, Custom Labels
2. Divider: `<li role="separator" class="nav-dropdown-divider">` — `border-top: 1px solid rgba(74, 111, 75, 0.2); margin: 4px 0; pointer-events: none`
3. Group 2 (new): All Ingredients | Hops | Grains | Yeast | Additives | Packaging | Equipment (7 links)

**Width:** `min-width: 200px` (increased from existing 180px to accommodate longer labels without wrapping)

**Dropdown behavior:** Claude's discretion on "Ingredients & Supplies" label — resolved: "All Ingredients" is a clickable link to `products/ingredients-supplies.html`. It does not become a non-clickable section header. Rationale: a clickable "All" link is more useful and consistent with the rest of the group.

### Existing: Subpage Hero (from Phase 21, unchanged)

Carries forward from `css/catalog-subpage.css`. Each new subpage sets `SUBPAGE_CONFIG.accentColor` which `applyHeroAccent()` maps to `--subpage-accent` on the hero element.

### Existing: Product Card Grid (from Phase 21, unchanged)

`16-catalog-subpage.js` renders the grid. No visual changes in this phase.

### Existing: Cart Drawer (from Phase 21, unchanged)

Standard `.cart-drawer` pattern. No FAB on the 5 new subpages (FAB is hops-only, handled by `15-hops.js`).

## Accessibility Contract

| Element | Requirement |
|---------|-------------|
| Sub-nav landmark | `<nav aria-label="Ingredient categories">` |
| Active pill | CSS active state is visually clear (filled green); no `aria-current` attribute needed since navigation is page-load not AJAX |
| Disabled search button | `disabled` attribute (not `aria-disabled`) — removes from tab order until Phase 23 wires it |
| Dropdown divider | `role="separator"` on `<li>` |
| Focus ring | `outline: 2px solid var(--color-green); outline-offset: 2px` on all interactive elements (matches site-wide focus pattern) |
| Mobile touch targets | 36px min-height on pills meets WCAG 2.5.5 Target Size (AAA at 44px recommended; 36px acceptable for supplementary nav with adjacent spacing) |
| Color contrast | Green (#4a6f4b) on cream (#e5dec1): ~5.1:1 — passes WCAG AA for normal text |

Note: MEMORY.md flags H14 (WCAG contrast failures on muted text) as an open issue. This phase does not introduce new muted text; `--color-muted: #5f5f5f` on cream is used only for the disabled search icon (opacity: 0.5), which is a non-informational decorative element.

## Implementation Notes for Executor

1. **Sticky z-index:** Sub-nav `z-index: 190` — one layer below site header `z-index: 200`.
2. **`--header-height` fallback:** Always `top: var(--header-height, 80px)` — never hardcode a pixel value.
3. **No new JS for active state:** `body[data-page]` + `[data-subnav]` CSS selectors handle active state entirely. No JS mutation of class names.
4. **Search button is `disabled`:** Not `aria-disabled`. Removes it from tab order; Phase 23 will remove the `disabled` attribute and add the handler.
5. **CSP meta tag:** All new pages must include the same `Content-Security-Policy` meta tag present in `hops.html` line 19. (Source: RESEARCH.md Security Domain.)
6. **Build pipeline:** Remove `hops.html` from `stamp:pages`; add all 6 new/moved pages. (Source: RESEARCH.md Pitfall 3.)
