## Join edge cases & data hygiene

| Option | Description | Selected |
|--------|-------------|----------|
| 'Unknown' bucket, sorts last | Distinct from 'Other'; surfaces data gaps | ✓ |

|--------|-------------|----------|

| Option | Description | Selected |
|--------|-------------|----------|
| Normalize + numeric sort for time | Merge '5 week'→'5 weeks'; time sorts 4/5/6/8; others by count | ✓ |

**User's choice:** 'Unknown' bucket (sorts after 'Other'); wine membership via `resolveBatchType()==='wine'`; normalize time + numeric week sort.
**Notes:** Unmatched/empty kept separate from the long-tail 'Other'; catalog join used only for the dimension value, never for wine membership.
