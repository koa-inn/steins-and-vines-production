#### 1. Wine Breakdown Card Placement and Batches-by-Month Untouched

**Test:** Open `brewpad.html` (logged in via Google OAuth) and look at the dashboard.
**Expected:** "Wine Breakdown" section header appears directly below the Batches-by-Month stacked-bar chart. The Batches-by-Month chart itself looks and behaves exactly as before — legend type chips still toggle series on/off.
**Why human:** DOM placement and visual rendering cannot be verified by grep.

#### 2. Default Subcategory Selection and Selector Chip Appearance

**Test:** With no prior interaction, observe the Wine Breakdown card's selector row.
**Expected:** Four chips labeled Subcategory / Brand / Manufacturer / Time. The Subcategory chip has a filled burgundy (#7b2d3b) background, white text, and `aria-pressed="true"` (verify in DevTools). Bars below show subcategory breakdown (Red / White / Fruit / Rosé / Specialty) sorted by count descending.
**Why human:** Visual chip state and bar content are data-dependent on live batch records.

#### 3. Dimension Switching and Time Sort Order

**Test:** Click each of Brand, Manufacturer, Time in sequence. For Time, examine the bar order.
**Expected:** Each click re-renders with the correct dimension. Time bars must appear ordered 4 weeks, 5 weeks, 6 weeks, 8 weeks (ascending week number) regardless of their counts. If any batch used '5 week' (singular), it should be merged with '5 weeks' bars into a single row.
**Why human:** Sort order of Time bars and singular/plural merge require live catalog join to observe.

#### 4. Period Selector Appearance and Behavior

**Test:** Confirm the period selector row (below dimension chips). Default is 6 Months. Click 30 Days.
**Expected:** Five chips: 30 Days / 90 Days / 6 Months / 12 Months / All Time. 6 Months chip is visually active (#5b4a7b purple) with `aria-pressed="true"`. After clicking 30 Days: bars and/or empty state update to reflect only batches from the last 30 days. If switching to All Time: bars include all historical wine batches.
**Why human:** Period chip visual state and dynamic data output require a running browser.

#### 5. Snapshot Fetch Failure Graceful Degradation

**Test:** In Chrome DevTools Network tab, right-click a request and block `/content/zoho-snapshot.json`. Reload the page.
**Expected:** The Wine Breakdown card shows a muted italic message "Unable to load catalog data — wine breakdown unavailable." The Batches-by-Month chart, Needs Attention section, and all other BrewPad content still renders normally. No JavaScript error in the console.
**Why human:** Fetch-failure path requires simulated network failure in a browser.

#### 6. Keyboard Accessibility

**Test:** Tab to a dimension selector chip. Press Enter to switch to Brand. Press Space to switch to Manufacturer.
**Expected:** Each key press triggers a dimension change and re-renders the bars. The newly active chip has `aria-pressed="true"` (inspect in DevTools Accessibility pane). The period chips have the same Enter/Space behavior.
**Why human:** Keyboard event handling and aria-pressed state updates require browser interaction.
