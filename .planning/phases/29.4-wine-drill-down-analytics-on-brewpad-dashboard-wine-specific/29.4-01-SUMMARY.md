# Phase 29.4 Plan 01: Wine Breakdown Pure Helpers + Jest Suite Summary

**One-liner:** Four pure ES5 helpers (buildSkuLookup, normalizeWineTime, bucketWineDimension, applyTopN) powering the Wine Breakdown card data layer, exported for Jest and covered by 34 passing tests.

## What Was Built

Added four pure helper functions at top-level scope in `js/brewpad.js` (immediately after `bucketBatchesByMonthType`, before `isSessionStale`), and a new Jest test suite `tests/frontend/brewpad-wine-breakdown.test.js` with 34 tests.

### buildSkuLookup(products)
Maps `products[]` to `{ String(sku): product }` lookup. Skips falsy sku entries. Later duplicate sku wins (last-write). Structural analog of `buildScheduleCategoryById`.

### normalizeWineTime(timeStr)
Returns `{ label: string, week: integer }`. Matches `/^(\d+)\s*weeks?/i` and canonicalizes to `<n> weeks` (plural), extracting the integer week count for ascending sort. Non-matching strings return `{ label: trimmed, week: 9999 }` -- sentinel value ensures they sort last. This is the singular/plural merge mechanism: '5 week' and '5 weeks' both produce `label:'5 weeks', week:5`.

### bucketWineDimension(batches, scheduleCategoryById, skuLookup, dimension, monthsBack, now)
Core bucketing function. Wine membership gate: `resolveBatchType(b, scheduleCategoryById) === 'wine'` (D-11). 6-month window using `start_date || created_at` sliced to 'YYYY-MM' (D-03). SKU join via skuLookup; missing or empty dimension value goes to 'Unknown' bucket (D-10). Sort: time dimension by week ascending (D-12), all others by count descending (D-02). Unknown always appended last. Does NOT call applyTopN -- returns full list.

### applyTopN(buckets, n)
Pure collapse function. Splits out 'Unknown', handles normal buckets: if count <= n, returns them unchanged. If > n, sorts by count desc, keeps first n, sums remainder into `{ label:'Other', count:sum }`. Appends 'Other' after top-n (D-09), then 'Unknown' last (D-10). Does not mutate input array.

### module.exports extension
Added `buildSkuLookup`, `normalizeWineTime`, `bucketWineDimension`, `applyTopN` to the existing guard at the bottom of `js/brewpad.js`. All existing exports preserved.
