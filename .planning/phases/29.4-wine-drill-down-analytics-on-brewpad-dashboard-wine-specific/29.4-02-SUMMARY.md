# Phase 29.4 Plan 02: Wine Breakdown Card UI Summary

**One-liner:** Wine Breakdown card below Batches-by-Month chart with segmented [Subcategory][Brand][Manufacturer][Time] selector, horizontal bars from Plan 01 helpers, lazy snapshot fetch, and graceful error/empty states.

## What Was Built

### State Variables (line ~651 in js/brewpad.js)

Three new in-memory state vars added alongside `_dashChartHiddenTypes`:

- `_dashWineDimension = 'subcategory'` — active dimension, defaults to Subcategory (D-04), resets to 'subcategory' on reload (D-06)
- `_dashWineSkuLookup = null` — cached sku→product map; null = not yet loaded
- `_dashWineSkuError = false` — set to true if snapshot fetch fails
- `_dashWineSkuLoading = false` — in-flight guard preventing re-entrant fetch

### loadWineSnapshot() Lazy-Fetch Function

Added before `renderDashboard()`. On first call (when `_dashWineSkuLookup === null && !_dashWineSkuError && !_dashWineSkuLoading`):
1. Sets `_dashWineSkuLoading = true`
2. Fetches `/content/zoho-snapshot.json`, checks `.ok`, parses `.json()`
3. On success: `_dashWineSkuLookup = buildSkuLookup(snap.products || [])` then `renderDashboard()`
4. On failure: `_dashWineSkuError = true` then `renderDashboard()` (T-29.4-02 mitigation)

### Wine Breakdown Card Render Block

Injected immediately after the Batches-by-Month closing brace, before the "Attention items" comment. Batches-by-Month block is byte-unchanged (D-01).

**Header:** `<div class="bp-section-header">Wine Breakdown</div>`

**Error state:** Muted italic note using `bp-empty` styling; rest of dashboard unaffected (T-29.4-02).

**Loading state:** Triggers `loadWineSnapshot()` once; shows "Loading…" placeholder.

**Segmented selector (D-04, D-05, D-06):**
- Four chips: Subcategory / Brand / Manufacturer / Time
- Each: `role="button"`, `tabindex="0"`, `aria-pressed="true/false"`, `data-bp-wine-dim="<dim>"`
- Active chip: filled burgundy background (#7b2d3b), white text, bold; inactive: white background, border #ddd
- Labels escaped via `escapeHTML()`

**Data pipeline (D-07, D-10, D-11, D-12):**
```
buildScheduleCategoryById(_fermSchedules)
→ bucketWineDimension(_allBatchesData, schedCatMap, _dashWineSkuLookup, _dashWineDimension, 6)
→ applyTopN(rawBuckets, 8)   // top-8 + Other + Unknown
```

**Empty state:** `<p class="bp-empty">No wine batches started in the last 6 months.</p>`

**Horizontal bars (D-02):**
- Each bucket: left label (90px, ellipsized), percent-width fill bar, right count label
- `WINE_DIM_PALETTE = ['#7b2d3b','#a34a2b','#c8852a','#d4a72c','#4a6f4b','#3a9aa6','#5b6dc8','#9c5bb5']` assigned by index
- 'Other' → `#9aa0a6` (matches TYPE_COLORS.other); 'Unknown' → `#c0b8b0`
- All labels passed through `escapeHTML()` (T-29.4-01 mitigation)
- Minimum bar width 2% to keep near-zero values visible
- Total label below bars: "Total: N wine batch(es)"

### Click/Keydown Handlers (Task 2)

**Click handler** (inside `dashInner.addEventListener('click', ...)`):
```js
var wineDimChip = e.target.closest('[data-bp-wine-dim]');
if (wineDimChip) {
  var wdim = wineDimChip.getAttribute('data-bp-wine-dim');
  if (wdim && wdim !== _dashWineDimension) { _dashWineDimension = wdim; renderDashboard(); }
  return;
}
```

**Keydown handler** (inside `dashInner.addEventListener('keydown', ...)`, guarded by Enter/Space):
```js
var kWineDim = e.target.closest('[data-bp-wine-dim]');
if (kWineDim) {
  e.preventDefault();
  var kwdim = kWineDim.getAttribute('data-bp-wine-dim');
  if (kwdim && kwdim !== _dashWineDimension) { _dashWineDimension = kwdim; renderDashboard(); }
}
```
