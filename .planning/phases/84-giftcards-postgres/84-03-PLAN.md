<interfaces>
Lookup (existing, extended by 84-07): GET /api/kiosk/gift-card/lookup?cert_number=GC-NNNNNN
  200 {ok:true, data:{cert_number, current_balance:Number, face_value:Number, status, ..., store_mode:'sheets'|'dual'|'postgres'}}
  (store_mode absent on an older middleware -> treat as 'sheets')

Adjust (NEW, implemented by 84-07): POST /api/kiosk/gift-card/adjust  (JSON, sent via _kcMergeAuth)
  body: { cert_number:'GC-NNNNNN', delta:Number (signed, non-zero, <= 2 dp),
          reason:'correction'|'goodwill'|'refund-to-card'|'other', note:String (required when reason 'other', <= 512),
          actor_name:String (1-60 chars, contains a letter), device_label:String (/^[A-Za-z0-9 _.-]{1,40}$/),
          adjust_key:String (/^[A-Za-z0-9-]{8,64}$/) }
  200 {ok:true, data:{cert_number, current_balance:Number, status, idempotent:Boolean}}
  400 {error:'<validation message>'}
  403 {ok:false, error:'adjust_unavailable', store_mode:'sheets'}
  404 {ok:false, error:'Certificate not found'}
  409 {ok:false, error:'invalid_status', status} | {ok:false, error:'negative_balance', balance:Number}
  503 {error:'Gift card service temporarily unavailable'}

Existing kiosk-core.js helpers: _kcMergeAuth(opts) attaches kiosk auth; _kcEnv.mwUrl; showToast(msg, type);
localStorage key already used: 'sv-kiosk-view-mode'.
