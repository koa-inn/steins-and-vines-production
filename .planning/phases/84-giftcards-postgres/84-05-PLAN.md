Apps Script request shape used today (pos.js confirm chain + routes/gift-cards.js callAppsScript):
axios.post(process.env.APPS_SCRIPT_URL, JSON.stringify({action, server_token: process.env.APPS_SCRIPT_SERVER_TOKEN, ...fields}),
           {headers:{'Content-Type':'application/json'}, timeout:12000, maxRedirects:5}) -> resp.data
Fields today: lookup_gift_card {cert_number}; get_next_cert_number {}; redeem_gift_card {cert_number, amount, transaction_ref: refNumber};
issue_gift_card {cert_number, face_value, issued_by, notes}; update_gift_card_invoice {cert_number, zoho_invoice_number};
reload_gift_card {cert_number, amount, transaction_ref: refNumber}; void_gift_card {cert_number, reason}

Facade API this plan CREATES (all return Promises; results are Apps-Script-shaped with underscore keys stripped):
- getMode() -> mode string
- isConfigured() -> sheets: !!(APPS_SCRIPT_URL && APPS_SCRIPT_SERVER_TOKEN); dual/postgres: db.isConfigured()
- mintTxRef(saleRef, certNumber, kind) -> saleRef + ':' + certNumber + ':' + kind (saleRef truncated so the result is <= 200 chars)
- actorFromRequest(req, prefix) -> prefix + ':' + (req.staffEmail ? 'session:' + req.staffEmail : (req.authTier || 'unknown'))
- lookup(certNumber, {compare}) -> {ok:true, data:{cert_number, current_balance:Number, face_value:Number, status, ...}} | {ok:false, error}
- nextCertNumber() -> {ok:true, suggested} | {ok:false, error}
- issue({certNumber, faceValue, issuedBy, notes, saleRef, actor, postCharge, txRef?})
- redeem({certNumber, amount, saleRef, actor, postCharge, txRef?})
- reload({certNumber, amount, saleRef, actor, postCharge, txRef?})
- voidCard({certNumber, reason, actor})
- updateInvoice({certNumber, invoiceNumber})
- adjust({certNumber, delta, reason, note, actorName, deviceLabel, adjustKey, actor})  (tx_ref = mintTxRef('ADJ-' + adjustKey, cert, 'adjust'))
- replayPending(record) -> re-invokes record.op with record.params (txRef verbatim, postCharge false); sheets mode -> {ok:false, error:'store_mode_sheets'}
- buildMirrorPayload(card, ledger) -> mirror_gift_card_state payload (contract in 84-02)
Transport/DB failures REJECT the promise; business outcomes RESOLVE with {ok:false, error}.
