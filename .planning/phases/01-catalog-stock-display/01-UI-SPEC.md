## Interaction Contract

### Stock Overflow Warning (STOCK-02, D-01 through D-03)

**Trigger conditions:**
- Grid card click → `kioskAddToCart(product)` → new cart qty would exceed `stock_on_hand` AND `stock_on_hand > 0`
- Cart `+` button → `kioskSetQty(itemId, newQty)` → same overflow condition
- Cart qty input `.change` event → `kioskSetQty(itemId, newQty)` → same condition
- NOT triggered on cart input `.input` event (would fire per keystroke — see RESEARCH.md Pitfall 3)
- NOT triggered for weight items (`kioskIsWeightItem` returns true) — see RESEARCH.md Pitfall 1
- NOT triggered for service items (`product_type === 'service'`)

**Dialog pattern:** Native `window.confirm()` — matches existing out-of-stock dialog exactly (D-03)

**Dialog copy (Claude's discretion — prescribed below):**
```
"[Product Name]" — only [N] in stock, cart would have [M]. Add anyway?
```
- `[Product Name]` = `product.name || 'This item'` — wrapped in quotes
- `[N]` = `parseFloat(product.stock_on_hand)` — integer display (no decimals for non-weight items)
- `[M]` = the incoming new cart total qty

**User choices:**
- Cancel → abort the add/qty change, cart unchanged
- OK → proceed with add/qty change regardless of stock

**Existing out-of-stock confirm (D-04, unchanged):**
```
"[Product Name]" is out of stock. Add to cart anyway (special order)?
```
This fires when `stock_on_hand <= 0`. The new overflow check fires when `stock_on_hand > 0` but `newQty > stock_on_hand`. These are mutually exclusive conditions.

---

### Category Filter Cleanup (CAT-01, CAT-02)

**`kioskItemCategory(p)` return value:**
- Returns `p.category_name || ''`
- Never returns `p.cf_type` or `p.product_type`

**Category filter `<select>` options:**
- "All Categories" (value `''`) — always first option
- One `<option>` per unique non-empty `category_name`, sorted alphabetically
- "Other" (value `'__other__'`) — appended last, only if at least one product has empty `category_name` within the current type filter scope

**Product card category badge:**
- Non-empty `category_name`: render badge as before
- Empty `category_name`: no badge rendered, no "Other" text, no empty element

**`kioskGetFilteredProducts()` addition for "Other":**
- When `_kioskFilters.category === '__other__'`: include only products where `kioskItemCategory(p) === ''`

**Beer card fallback (`kioskCbRenderBeerCard`):**
- `escapeHTML(cat || 'Beer')` remains unchanged — this is a card display fallback, not a filter value (see RESEARCH.md Pitfall 5)

## States to Implement

### Product Card States (stock display)

| State | Condition | Visual Treatment |
|-------|-----------|-----------------|
| In stock | `stock_on_hand > lowThreshold` | Stock count in `.kiosk-product-stock` (ink-tertiary text) |
| Low stock | `stock_on_hand > 0 && stock_on_hand <= lowThreshold` | `.kiosk-product-stock--low` (warning color, semibold) |
| Out of stock | `stock_on_hand <= 0` | `.kiosk-product-stock--out` (danger color, semibold) + `.kiosk-product-card--out-of-stock` (opacity 0.55) |

Note: Low stock threshold is determined by existing `kiosk.js` logic (STOCK-01 is verify-only — no new threshold logic).

### Category Badge States

| State | Condition | Visual Treatment |
|-------|-----------|-----------------|
| Category shown | `category_name` is non-empty | Badge rendered with category text |
| No badge | `category_name` is empty/missing | Badge element not rendered (no hidden element, no empty string) |

### Overflow Confirm States

| State | Condition | Visual Treatment |
|-------|-----------|-----------------|
| No dialog | `newQty <= stock_on_hand` OR weight item OR service | Proceed silently |
| Overflow dialog | `stock_on_hand > 0` AND `newQty > stock_on_hand` | Native `confirm()` with overflow copy |
| Override granted | User clicks OK | Cart qty set to newQty |
| Override declined | User clicks Cancel | Cart unchanged, qty reverted |
