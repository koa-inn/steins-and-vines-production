<objective>
Rewrite the kiosk's auth model in `js/kiosk.js`: **remove the entire Google-sign-in gate** (`initGoogleAuth`, `showSignInButton`, `onTokenResponse`, `kioskCheckAuthorization`, the periodic token-refresh timer, the `google.accounts.oauth2.revoke` sign-out, `handleUnauthorized`) and replace the entry gate with a **typed-in device token** (D-46-01) persisted in `localStorage` and sent as the `x-device-token` header on every kiosk API call in place of `SHEETS_CONFIG.MW_API_KEY`. Migrate the three customer-search call sites off the full-PII `/api/contacts?search=` onto the narrow `/api/contacts/search?q=` (Finding #2 scope-leak fix).

Purpose: The in-store iPad is a trusted shared terminal; staff should not need a Google account to ring up a sale, and no shared middleware secret ships to the browser. Do NOT run `npm run build` here — the single rebuild happens in 46-09.
Output: rewritten `js/kiosk.js`, a new frontend test for device-token persistence/gating.
</objective>
