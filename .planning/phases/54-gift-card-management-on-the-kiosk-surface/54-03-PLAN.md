<objective>
Add a frontend regression test that locks in the kiosk kgcm- panel's device-token auth path and its void confirmation gating — the two properties that make D-54-GC's scope widening safe on the client side. The admin test (`tests/frontend/admin-gift-card-mgmt.test.js`) covers the admin cookie path; this new test covers the kiosk device-token path and adds the reason-required negative case the admin file lacks.
