<objective>
Author a kiosk-native Gift Card Management panel (`kgcm-*`: balance lookup + void, D-54-05) in the shared `js/kiosk-core.js`, add its overlay markup and a settings-gated entry button to `kiosk.html` / `js/kiosk.js`, and rebuild the kiosk bundles. The admin page already has this via its `openModal`-based `kgcm-*` modal, but the kiosk page has no modal system — so this is built fresh, mirroring the existing `kgcr-` redeem panel and `kioskShowDiscountMgmt` overlay, using the injected `buildAuthOptions()` per-surface auth.

Purpose: The owner manages gift cards from the standalone kiosk. Placement is behind the hidden Device Settings gate (D-54-01) because void is money-destroying and must not be a mistap away during a sale. Behavior parity with the admin two-step flow is the explicit requirement (D-54-02); only the auth mechanism differs.

Output: `kioskShowGiftCardMgmt()` + `showGiftCardMgmt` export in kiosk-core; `kgcm-` overlay + entry button in the markup; rebuilt `kiosk-core.min.js` / `kiosk.min.js`; frontend suite + lint green. (Plan 03 adds the regression test.)
</objective>
