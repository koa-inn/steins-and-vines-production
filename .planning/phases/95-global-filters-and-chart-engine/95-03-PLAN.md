- `bucketKeyOf(ymd, group)` -> week: Monday 'YYYY-MM-DD'; month: 'YYYY-MM'
- `bucketLabelOf(key, group)` -> month 'Jun 2026'; week 'Week of Jun 1'
- `periodSkeleton(start, end, group)` -> [{key, label}] gap-filled, first bucket contains start, last contains end
- `sourceMatches(row, want)` -> want 'all'|''|undefined true; 'unknown' -> normBatchSource === ''; 'kiosk' -> 'kiosk' or 'kiosk_recipe'; else equality
- `batchLitres(row, kind, type)` -> {l, est}; kind 'started'|'active'|'completed'
- `isStaffRow(row, staffIds)` -> row.staff_batch === true || (staffIds && staffIds[row.batch_id] === true)
- `windowFromFilters(state, today)` -> state.period in '30d'|'90d'|'6mo'|'12mo'|'ytd'|'all' -> dashboardWindow; 'custom' with valid from<=to<=today -> {key:'custom', start: from, end: to}; invalid custom -> ytd window
- `previousWindow(win, today)` -> null for key 'all'; 30d/90d/6mo/12mo/custom: N = dayNumber(end)-dayNumber(start)+1, {key, start: addDays(win.start, -N), end: addDays(win.start, -1), days: N}; ytd: {key:'ytd', start: (year-1)+'-01-01', end: same month-day last year, Feb 29 -> Feb 28}
- getDashboardData new filter keys: `range {start,end}` (overrides window; win.key = f.window || 'custom'), `source`, `staff` (bool), `staffIds` (map), `group` ('week'|'month')
- getDashboardData new return keys (always present):
  - `ids: { started:[], completed:[], activeNow:[], cycle:[], startedByType:{5 types:[]}, completedByType:{5 types:[]} }`
  - `litres: { started, completed, activeNow, startedByType:{}, completedByType:{}, estimated: bool }`
  - `periodBuckets: [{ key, label, ids:{5 types:[]}, all:[], counts:{5 types}, total, litres:{5 types}, totalLitres }]` ([] when no group)
  - `mix: { wine: [rows], staffHidden: n }` — wine rows, started status, start_date in window, after type and source filters, staff rows removed unless f.staff
  - `earliestStart` — min start_date over ALL input rows with a started status (before any filter), or null
