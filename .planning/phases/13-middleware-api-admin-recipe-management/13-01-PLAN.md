**WR-02 + WR-03 combined: Fix _invalidateRecipeCache (around line 2938)**
Replace the body of `_invalidateRecipeCache(recipeId)` with:
```javascript
function _invalidateRecipeCache(recipeId) {
  var cache = CacheService.getScriptCache();
  var keys = [];
  ['all', 'draft', 'active', 'inactive'].forEach(function(s) {
    keys.push('gr:list:' + s + ':0:0');
  });
  if (recipeId) {
    keys.push('gr:' + recipeId);
  }
  cache.removeAll(keys);
}
```
This removes the dead `'grl'` key (WR-02) and clears all status-variant keys introduced by WR-03.
