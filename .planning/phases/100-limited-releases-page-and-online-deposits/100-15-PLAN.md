Inside left-aligned `.container` sections this centres the paragraph block, so the hero sub-copy, "Release months are set by the suppliers…", the basket empty-state text, the "Kit price shown…" note, the "Up to 10 kits…" line and the confirmation's "Deposit paid…" / "We have emailed…" lines all sit indented ~200px from the section's left edge. Kit-card paragraphs get margin-left 16px from the same rule.
2. Calendar `<li class="lr-calendar__month"><strong>Month</strong><span class="lr-calendar__kit">…</span></li>` has no layout: month and kit names run together ("November 2026Ember RJS", "January 2027Connexion White WinexpertAria RJS").
3. Spec chip rows wrap with the chip separator border starting the new line (e.g. "| 13.5% ABV").
4. Collection grids are 3 columns; 5 kits leave a row of 2 + an empty cell.
5. RJS Elemento hero (images/limited-releases/…) is cropped: the supplier's left-side text is cut ("o", "d.").
6. Very large empty vertical bands above/below each stein-icon divider; "How it works" heading/columns feel detached.
7. Confirmation panel (screenshots in 100-STAGING-RUN.md Step 1): centred/offset lines (root cause 1), ordered list markers hang outside the card padding, "What happens next" heading larger than "Your deposit is paid", buttons touching.
8. "SO SO-000085": js/modules/18-limited-releases.js line ~1173 and zoho-middleware/lib/mailer.js line ~521 prefix "SO " to a number that already starts with "SO-".
9. Reserve form: helper lines offset (root cause 1); spacing between fields/consents/button uneven.
