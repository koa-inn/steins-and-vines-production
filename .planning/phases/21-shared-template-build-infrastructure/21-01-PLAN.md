## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API response -> DOM | Product data from /api/ingredients rendered into page DOM |
| URL params -> JS | ?item=SKU deep-link parameter read by handleDeepLinkedItem |
| localStorage -> JS | Cached product data read from localStorage |
| SUBPAGE_CONFIG -> JS | Page-defined config object read at init |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01 | Tampering | Product names in DOM | mitigate | Use el.textContent for all product data — never innerHTML. escapeHTML() available if innerHTML needed for structured content |
| T-21-02 | Tampering | Custom field flattening in mapItem | mitigate | Prototype pollution guard: skip keys '__proto__', 'constructor', 'prototype' in custom_fields forEach |
| T-21-03 | Tampering | Search query in DOM | mitigate | Search query used only in Fuse.search() and textContent comparison — never set as innerHTML |
