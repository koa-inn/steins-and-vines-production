## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inline padding |
| sm | 8px | Card inner gaps, filter pill padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Hero section inner padding, toolbar padding |
| xl | 32px | Section margin, grid row gap |
| 2xl | 48px | Hero top/bottom padding (matches hops hero `padding: 5rem 0` ≈ 80px; hero is constrained to ~150px by D-05 — use 48px top/bottom) |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Hero padding: 48px top/bottom (D-05 requires ~150px total hero, short enough that products are immediately visible without scrolling)
- Touch targets for sort/filter controls: minimum 44px height
- Grid card minimum width: 250px (D-03)
- Detail panel margin-top: calculated dynamically in JS (negative row height + gap) — not a static token

## Typography

All sizes in rem at base 16px = 1rem. Source: `css/styles.css:142,149,193,197-214` and `css/hops.css` hero/card patterns.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 1rem (16px) | 400 | 1.6 | Card descriptions, detail panel body text, toolbar intro, hero short description, hero "Read more" expanded paragraph |
| Label | 0.875rem (14px) | 700 | 1.5 | Filter pills, sort options, stock badges, price labels, table row cells, card metadata, "Read more" toggle link |
| Heading | 1.5rem (24px) | 700 | 1.2 | Card product name (h2), detail panel heading |
| Display | clamp(1.625rem, 4vw + 1rem, 3rem) | 700 | 1.2 | Hero h1 category name (matches hops hero h1 pattern) |

Typography rationale for collapsed sizes:
- Hero short description uses Body (1rem, weight 400) — it is running text differentiated from the heading by context and weight contrast, not a distinct size.
- Stock badge text uses Label (0.875rem, weight 700) — its visual identity comes from background color and border-radius; a smaller size is redundant and breaks the 4-size constraint.

## Color

Source: `css/styles.css:118-129`. All tokens are CSS custom properties already declared globally.

| Role | Value | CSS Token | Usage |
|------|-------|-----------|-------|
| Dominant (60%) | `#e5dec1` | `--color-cream` | Page background, card background, toolbar background, detail panel background |
| Secondary (30%) | `#4a6f4b` | `--color-green` | Hero background, active filter pills, primary buttons ("Add to Cart"), nav borders, sort control accent |
| Accent (10%) | Per-category via `--subpage-accent` | injected by JS from `SUBPAGE_CONFIG.accentColor` | Hero border/underline accent, active card highlight border, filter pill active state highlight stripe |
| Destructive | `#c0392b` | `--color-error` | Not used in this phase — no destructive actions on catalog pages |

Accent reserved for: hero bottom border/accent stripe, `.subpage-card--active` left-border highlight (4px solid), filter pill active state left-border or underline stripe. The accent does NOT replace `--color-green` on buttons or interactive controls — it supplements with a per-category tint only.

Per-category accent color assignments (Claude's discretion per D-06, within green/brown/amber palette):

| Category | Accent Hex | Rationale |
|----------|------------|-----------|
| Grains | `#8b6f3a` | Warm amber/malt — evokes toasted grain |
| Yeast | `#c4a35a` | Gold — fermentation activity, living culture |
| Additives | `#5a7a3a` | Olive green — botanical/additive feel |
| Packaging | `#4a5a6b` | Slate blue — neutral, structural |
| Equipment | `#6b4c2a` | Dark brown — tools, hardware |

These values are defaults for Phase 22. Phase 21 ships the infrastructure — the test subpage uses `#8b6f3a` (grains accent) as its demonstration value.

Muted text color: `#5f5f5f` (`--color-muted`) — used for helper text, "Read more" toggle, secondary card metadata.

Out-of-stock overlay: card retains full color but cart controls are hidden and replaced with the stock badge. No opacity reduction on the card image/name (product is still discoverable).

## Component Inventory

Components delivered in `css/catalog-subpage.css` and `js/modules/16-catalog-subpage.js`:

### Hero Section (`.subpage-hero`)
- Background: `--color-green` (consistent with hops hero)
- Accent stripe bottom: 6px zigzag SVG border in `--subpage-accent` color (adapts the hops `::after` zigzag pattern)
- Height: ~150px total (48px top + 48px bottom padding + h1 + description line)
- h1: Display font, weight 700, `--color-cream`
- Short description (`.subpage-hero-desc`): 1rem (Body), weight 400, `--color-cream`, max-width 40ch centered
- "Read more" toggle (`.subpage-hero-toggle`): 0.875rem (Label), weight 700, `--color-cream`, underline style, cursor pointer. Expands `.subpage-hero-full` which is `display: none` by default (visible to crawlers via JS unhide on click, not CSS `visibility: hidden`)

### Product Grid (`.subpage-catalog-grid`)
- CSS grid, `grid-template-columns: repeat(auto-fill, minmax(250px, 1fr))`, max 4 columns at wide viewports
- Row gap: 24px (lg). Column gap: 16px (md)
- Cards: extend `.product-card` from `css/styles.css` — do NOT redeclare `.product-card` rules in `catalog-subpage.css`
- Card subclass: `.subpage-card`
- Active card: `.subpage-card--active` — 4px left border in `--subpage-accent`, no other change

### Expanded Detail Panel (`.subpage-detail-panel`)
- `grid-column: 1 / -1` — spans full grid width
- Background: `--color-cream`, border-top 3px solid `--color-green`
- Padding: 24px (lg)
- Close button: top-right corner, text "×", 1.5rem (Heading size), weight 700, color `--color-text`
- Content: product name (1.5rem Heading, weight 700), description (1rem Body, weight 400, line-height 1.6), weight options (if applicable), stock count, cart control
- Smooth scroll into view on open

### Sort Controls (`.subpage-sort`)
- Three sort options rendered as `<select>` or styled `<button>` group
- Options: "Name (A–Z)", "Name (Z–A)", "Price: Low to High", "Price: High to Low", "In Stock First"
- Active/selected: background `--color-green`, color `--color-cream`
- Default selection: "In Stock First" (D-07)

### Filter Pills (`.subpage-filter-pills`) — conditional
- Rendered only if `SUBPAGE_CONFIG.filterGroups` is non-empty (D-08)
- Pill: `<button>`, border 1px solid `--color-green`, background transparent, color `--color-green`, border-radius 20px, padding 8px 16px
- Active pill: background `--color-green`, color `--color-cream`
- "All" pill always present as first option, active by default

### View Toggle (`.subpage-view-toggle`)
- Two buttons: Grid icon (☰ → grid symbol) and List icon (≡)
- Active button: background `--color-green`, color `--color-cream`
- Inactive: border 1px solid `--color-green`, background transparent

### List View Table (`.subpage-list-table`)
- Full-width table, columns: Name | Price | Stock | Add to Cart
- Row height: minimum 44px
- Row hover: background `rgba(74, 111, 75, 0.08)` (green tint)
- Expandable detail row (`.table-detail-row`): `display: none` by default, toggled on row click; shows description + weight options inline

### Stock Badge (`.stock-badge`)
- Reuse existing class from `js/modules/08-catalog-ingredients.js`
- `.stock-badge--in`: background `--color-green`, color `--color-cream`, text "In Stock"
- `.stock-badge--out`: background `--color-muted`, color `--color-white`, text "Out of Stock"
- Size: 0.875rem (Label), weight 700, border-radius 4px, padding 2px 6px
- Out-of-stock cards: cart controls are omitted entirely (no button shown)

### Empty State (`.catalog-no-results` + `.catalog-no-results-sub`)
- Reuse existing class from `css/styles.css:2070`
- Center-aligned, padding 48px 16px
- Heading: 1rem (Body), color `--color-brown`
- Sub-message: 0.875rem (Label), color `--color-muted`

## Accessibility Notes

- All interactive controls (filter pills, sort, view toggle, detail panel close, "Read more") must be `<button>` elements, not `<div>` or `<span>` — keyboard focusable by default
- Sort `<select>` element uses native browser control — inherits keyboard behavior
- Detail panel open: move focus to panel heading or close button
- Detail panel close: return focus to the triggering card's "Details" button
- Stock badge uses `role="status"` or is purely presentational (badge beside interactive controls) — use `aria-label` on the Add to Cart button to include stock context: "Add [Product Name] to cart"
- WCAG contrast: `--color-green` (#4a6f4b) on `--color-cream` (#e5dec1) passes AA at 4.6:1. `--color-muted` (#5f5f5f) on `--color-cream` passes AA at 5.1:1. `--color-burgundy` (#370e13) on `--color-cream` passes AAA.
- Filter pills and view toggle buttons: minimum 44px height for touch targets
