| T-48-08O | Tampering (silent feature loss) | Manager Override stock gate | mitigate | Port admin's WORKING override into core (D-07) so `override` is sent and the 409/`conflicts`→`#kiosk-stock-override-btn`→resubmit flow survives on BOTH surfaces; the server 409 gate (pos-recipe.js:328) stays authoritative — the override is an explicit staff affordance, never an automatic bypass |
| T-48-SC | Tampering | npm installs | accept | Zero new dependencies this phase |
