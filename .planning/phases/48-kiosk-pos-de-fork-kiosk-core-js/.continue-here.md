## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Vars-≠-deploy | Setting Railway env vars does NOT ship code; Railway rebuilds the code already in the production repo. The code ship is the **Gated Production Deploy** workflow. | blocking | To deploy prod: run the workflow (GitHub Actions on staging repo → "Gated Production Deploy"). Never assume var changes = a deploy. |
| Wrong-key-rotated | `getKey() = API_SECRET_KEY \|\| MW_API_KEY`. New key pasted into `MW_API_KEY` did nothing (API_SECRET_KEY overrode it). | advisory | Rotate by setting `API_SECRET_KEY` AND deleting `MW_API_KEY`. |
| Local-main-force-push | `git push production main --force` would deploy LOCAL main (which has unverified Phase 48). | blocking | Deploy ONLY via the Gated Production Deploy workflow (ships `origin/main`, excludes Phase 48). |
