## Overlay Interaction Contract

Source: D-01, D-02, Claude's Discretion items from `23-CONTEXT.md`.

### Open / Close

| Trigger | Behaviour |
|---------|-----------|
| Click `.subnav-search-btn` | Open overlay; auto-focus search `<input>` |
| ESC key | Close overlay, return focus to `.subnav-search-btn` |
| Click backdrop | Close overlay |
| Click "View all" link | Navigate to category page (overlay closes via page unload) |

### Animation

- **Desktop dropdown:** fade-in + slide down 8px → 0px, duration 180ms ease-out. Matches existing 0.15s transition convention; 180ms is consistent with debounce timing.
- **Mobile full-screen:** fade-in from `opacity: 0` to `opacity: 1`, duration 200ms ease-out. No slide — avoids jank on low-end devices.
- **Close:** reverse of open, same duration.
- CSS approach: `opacity` + `visibility` + `transform: translateY(-8px)` for desktop (matches cart drawer `transform 0.3s ease` pattern, shortened to 180ms for snappier feel on a small panel).

### Responsive Layout

| Viewport | Layout |
|----------|--------|
| >= 768px (desktop) | Dropdown panel, anchored below sub-nav bar, `position: absolute`, `top: calc(100% + 4px)`, `right: 0`, `width: 480px`, `max-width: calc(100vw - 32px)`, `max-height: 60vh`, overflow-y scroll, `border-radius: 4px`, `box-shadow: 0 4px 20px rgba(0,0,0,0.2)` |
| < 768px (mobile) | Full-screen fixed overlay (`position: fixed; inset: 0`), dark backdrop behind, panel fills full width, `padding: 16px`, search input at top, results scroll below |

Breakpoint: `SUBPAGE_DESKTOP_BREAKPOINT = 768` (matches existing constant, source: `23-CONTEXT.md` line 96).

### Z-index Stack

| Layer | Z-index |
|-------|---------|
| Sub-nav bar | 190 (existing) |
| Search overlay backdrop | 195 (above sub-nav, below cart FAB at 1050) |
| Search overlay panel | 196 |

Note: Cart FAB sits at `z-index: 1050` (source: `catalog-subpage.css` line 689). The search overlay must NOT overlap the cart drawer (z-index 1200). Placing search at 196 keeps it sandwiched between sub-nav and cart FAB.

### Search Input

- Placeholder: `Search all ingredients...`
- Minimum 2 characters before Fuse fires (D-10)
- 180ms debounce (matches existing pattern, source: `23-CONTEXT.md` line 98)
- `<input type="search">` with `autocomplete="off"`, `spellcheck="false"`
- Clear (x) button appears when input has value: 32x32px, icon-only, `color: var(--color-muted)`

### Result Rows

Each row contains (left to right):
1. Product name — 16px / weight 400 / `--color-text` — full width, truncated with ellipsis at 2 lines
2. Price with unit — 14px / weight 400 / `--color-muted` — e.g. `$4.50/kg`, `$2.99 each`
3. Stock badge — 12px / weight 700 / white on green (in-stock) or white on muted (out-of-stock) — `border-radius: 3px`, `padding: 2px 6px`
4. Cart button — right side, 36x36px touch-friendly, icon-only `+` or stepper if already in cart

Row height: 48px min-height. Horizontal padding: 16px. Divider: `1px solid rgba(74,111,75,0.12)`.

Out-of-stock rows: `opacity: 0.5`, no cart button rendered (D-07).

### Weight-based Items (Cart Button)

Inline cart for weight items shows a simplified `+` that adds 1 unit of the smallest unit (e.g. 1 kg). No full weight input in the overlay — that complexity belongs on the subpage detail panel. Clicking the name navigates to the subpage for precise quantity entry.

### Group Headers

```
[Category Name]  (N)
```

- Category name: 13px / weight 700 / `--color-text`, `text-transform: uppercase`, `letter-spacing: 0.04em`
- Match count: 13px / weight 400 / `--color-muted` — format: `(5)` or `(12)`
- Left border: `3px solid var(--color-green)`, `padding-left: 8px`
- Background stripe: `rgba(74,111,75,0.05)`, full-width, `padding: 6px 16px`
- Bottom border: none — natural separation from first result row divider

### Dynamic Result Cap (D-06)

| Matching categories | Rows shown per group |
|---------------------|----------------------|
| 1–2 | 10 |
| 3–4 | 7 |
| 5+ | 5 |

"View all X in [Category]" link appears below the capped list, `font-size: 13px`, `color: var(--color-green)`, `font-weight: 700`, `padding: 6px 16px 8px`.

## Accessibility Contract

- Search `<input>` has `aria-label="Search all ingredients"` or associated visible `<label>`
- Overlay has `role="dialog"`, `aria-modal="true"`, `aria-label="Ingredient search"`
- Backdrop click closes overlay (D-02 + Claude's Discretion)
- Focus trap inside overlay while open; restore focus to `.subnav-search-btn` on close
- Result list: `role="list"`, each row `role="listitem"`
- Group headers: `role="heading"` `aria-level="3"`
- Cart button: `aria-label="Add {name} to cart"` (computed per row)
- All interactive elements meet 44px touch target minimum (matches existing sub-nav pill pattern)
- `prefers-reduced-motion`: disable translate animation, keep opacity-only fade
