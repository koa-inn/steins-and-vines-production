<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Search input -> Fuse.js | User-typed search query passed to client-side Fuse.search(); never sent to server |
| Search input -> DOM | Query echoed in "No ingredients match" message — must use textContent, not innerHTML |
| Middleware API -> Client | Ingredient data from /api/ingredients endpoint; items rendered via textContent only |
| localStorage -> Client | Cached ingredient data read from localStorage; same trust as existing 16-catalog-subpage.js pattern |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Tampering | Search input reflection | mitigate | Use el.textContent for "No ingredients match '{query}'" — never innerHTML. escapeHTML() only for HTML string construction of wrapper elements |
