<objective>
Make pending batches visible in the admin BrewPad batch list (BATCH-01). Widen the backend `active` filter to include pending, add a dedicated "Pending" filter option, give pending a distinct badge, and pin pending rows to the top so the work that needs doing is the first thing staff see.

Purpose: Today pending batches are silently excluded from the default list (`getBatches` `active` branch returns only primary/secondary), so staff never know a batch is waiting to be activated. This plan surfaces them.
Output: Pending batches show by default, are filterable, visually distinct, and pinned to top — the groundwork the two activation plans (27-02, 27-03) build on.
</objective>
