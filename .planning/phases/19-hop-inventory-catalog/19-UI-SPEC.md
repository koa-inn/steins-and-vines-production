## Interaction Contracts

### Accordion Expand / Collapse (D-08, D-12)

- Trigger: Click anywhere on the collapsed `.hop-card` (or dedicated "Hop Details ▾" toggle button — consistent with `buildLabelNotesToggle` pattern).
- Toggle button text (collapsed): "Hop Details ▾" 
- Toggle button text (expanded): "Hop Details ▴" (chevron rotates 180° via CSS transform, matching `.notes-wrap.open .chevron`)
- aria-expanded: "false" collapsed / "true" expanded.
- Max-height animation: 0 → 600px, `transition: max-height 0.3s ease`.
- Only one hop can be expanded at a time on mobile (<= 768px). On desktop, multiple can be open simultaneously (matches existing wine/beer card pattern).
- Scroll-padding ensures expanded card stays visible after opening.

### Size Variant Toggle (D-10, D-11)

- Two buttons: e.g. "1 oz" and "4 oz" (labels from Zoho SKU data).
- Default selected: smaller/cheaper size (index 0 in sorted size array).
- On toggle: update displayed price via JS. No page reload.
- Active button state: `border-color: var(--color-green)`, `color: var(--color-green)`.
- The single "Add to Cart" button always adds the currently selected size variant.
- aria-pressed="true/false" on each toggle button.

### Radar Chart Render (D-13, D-14, D-15)

- Rendered as inline `<svg>` built in JS at card expansion time (lazy render — not on page load).
- SVG dimensions: 200×200px viewBox, centered polygon.
- 6 axes equally spaced at 60° intervals: Citrus, Tropical, Floral, Spicy, Pine, Herbal (clockwise from top).
- Scale: 0–5. A score of 5 = full vertex at outer ring. A score of 0 = center point.
- Polygon fill: `rgba(74, 111, 75, 0.25)`.
- Polygon stroke: `var(--color-green)`, stroke-width 2.
- Background web lines: 5 concentric hexagons at scale 1–5, stroke `rgba(0,0,0,0.1)`, stroke-width 1.
- Axis lines: from center to each vertex, stroke `rgba(0,0,0,0.15)`, stroke-width 1.
- Axis labels: SVG `<text>` elements, font-size 12, fill `#5f5f5f`, text-anchor varies by position (start/middle/end to avoid clipping).
- If all 6 scores are 0 (no data), render greyed-out empty web with message "Sensory data coming soon" below chart in `.hop-notes` style.
- Accessibility: `role="img"`, `aria-label="{hop name} sensory profile: Citrus {n}/5, Tropical {n}/5, ..."`.

### Filtering (D-18)

- Flavor profile filter buttons: one button per dominant profile (Citrus, Tropical, Floral, Spicy, Pine, Herbal). Derived from 6 radar axes. A hop matches a filter if its score on that axis is >= 3.
- Multiple flavor filters can be active simultaneously (OR logic — show hops matching any selected profile).
- Text search: debounced 200ms, searches hop name and notes fields. Matches `.buildIngredientSearch` pattern.
- Sort options: Name (A–Z), Alpha Acid (High–Low), Price (Low–High). Default: Name A–Z.
- Active filter count badge on collapsible controls panel (matching `.filter-count-badge` pattern if present, else plain text).
- Filter state stored in module-level vars (not URL — matches existing ingredients pattern).

### Add to Cart (D-19)

- Uses `setReservationQty(product, qty)` from `11-cart.js`. Product `_item_type` must be `'ingredient'` so `getCartKey()` routes to `sv-cart-ingredients`.
- Adding shows toast: "Added to cart" (green, 2.5s auto-dismiss).
- If stock = 0: button shows "Out of Stock", disabled state, `opacity: 0.5`, cursor not-allowed.
- If stock > 0 and qty in cart already equals stock: button shows "Max in cart", disabled.

## Accessibility Requirements

- All interactive elements (filter buttons, size toggles, accordion, Add to Cart): minimum 44px touch target height.
- Filter buttons: `aria-pressed="true/false"` on active state.
- Accordion: `aria-expanded="true/false"` on toggle button; controlled panel has matching `id` and toggle has `aria-controls`.
- Size toggle: `aria-pressed="true/false"`.
- Radar SVG: `role="img"` with `aria-label` listing all 6 axis scores (screen-reader accessible data).
- Focus ring: `outline: 2px solid var(--color-burgundy); outline-offset: 2px` on `:focus-visible` (inherited from global styles).
- Color contrast: all body copy (`#2c2c2c` on `#fff` or `#e5dec1`) passes WCAG AA. Green accent (#4a6f4b) on white passes AA for large text; use only for decorative or large-text contexts.
- Reduced motion: SVG radar renders statically (no animation). Accordion max-height animation wrapped in `@media (prefers-reduced-motion: reduce) { transition: none }`.
