**Create `js/modules/15-hops.js`** as a standalone ES5 module (NOT in concat:js pipeline). This file follows the 14-labels.js standalone pattern. It loads after main.min.js so all shared globals (formatCurrency, renderReserveControl, setReservationQty, trackEvent, Fuse, etc.) are available.

**All code must be ES5:** `var` only, no arrow functions, no template literals, no const/let, no destructuring.

**Module structure (in this exact order):**

1. **Module-level state variables:**
```javascript
var _allHops = [];
var _hopGroups = [];
var _hopsFuse = null;
var _activeFlavorFilters = [];
```

2. **Constants:**
```javascript
var HOP_AXES = ['citrus', 'tropical', 'floral', 'spicy', 'pine', 'herbal'];
var HOP_AXIS_LABELS = ['Citrus', 'Tropical', 'Floral', 'Spicy', 'Pine', 'Herbal'];
var RADAR_NS = 'http://www.w3.org/2000/svg';
var RADAR_SIZE = 200;
var RADAR_CENTER = RADAR_SIZE / 2;
var RADAR_RADIUS = RADAR_SIZE * 0.34;
var RADAR_LABEL_OFFSET = RADAR_SIZE * 0.13;
var MW_CACHE_KEY = 'sv-hops-mw';
var MW_CACHE_TS = 'sv-hops-mw-ts';
var MW_CACHE_TTL = 3600000;
```

3. **`groupHopsByVariant(items)`** — Groups flat hop items by name stem. Strip trailing size suffix (` - 1 oz`, ` - 4 oz`, ` - 1oz`, ` - 4oz` etc.) using regex `/\s*[-–]\s*\d+\s*oz\s*$/i`. Items without a size suffix keep their full name as the stem. Sort variants within each group by `parseFloat(price_per_unit)` ascending. Returns array of `{name: stem, variants: [item1, item2]}`.

4. **`getTopFlavorTags(item, count)`** — Reads `item.citrus`, `item.tropical`, etc. as floats, sorts descending by value, returns top `count` (default 3) entries with `value > 0` as `[{label: 'Citrus', value: 4}, ...]`.

5. **`getDominantFlavor(item)`** — Returns the HOP_AXIS_LABELS string of the highest-scoring axis, or `null` if all scores are 0.

6. **`buildHopRadarChart(item)`** — Builds an inline SVG element per D-13, D-14, D-15:
   - SVG viewBox: `0 0 200 200`, class `hop-radar`, `role="img"`
   - `aria-label`: e.g. "Amarillo sensory profile: Citrus 4/5, Tropical 2/5, Floral 1/5, Spicy 0/5, Pine 3/5, Herbal 2/5"
   - Draw 5 concentric hexagonal web rings (at scale 1,2,3,4,5 out of 5) using `<polygon>` with class `radar-web`
   - Draw 6 axis lines from center to each vertex with class `radar-axis`
   - Draw 6 axis labels as SVG `<text>` elements with class `radar-label`, positioned outside the outermost ring. Use `text-anchor` logic: top axis = `middle`, right-side axes = `start`, left-side axes = `end`, bottom axis = `middle`. Add `dominant-baseline: middle` for vertical centering.
   - If any score > 0: draw score polygon with class `radar-fill`
   - All SVG elements created with `document.createElementNS(RADAR_NS, tagName)` -- NEVER `document.createElement`
   - Angles: start from top (- PI/2), go clockwise at 60-degree intervals

7. **`loadHops(callback)`** — Fetch hop data following 08-catalog-ingredients.js pattern:
   - Try localStorage cache first (MW_CACHE_KEY, check timestamp < MW_CACHE_TTL)
   - If cache miss: fetch from `middlewareUrl + '/api/ingredients'`
   - Map response items using the custom field flattening pattern (see interfaces above)
   - On middleware failure: fall back to `/content/zoho-snapshot.json` (`snap.ingredients` array)
   - After loading: filter to hop items only: `name.toLowerCase().indexOf('hop') !== -1 && name.toLowerCase().indexOf('pellet') !== -1` AND `parseFloat(price_per_unit) > 0` (per D-06: excludes packaging/zero-price)
   - Store in `_allHops`, group into `_hopGroups` via `groupHopsByVariant`
   - Initialize Fuse.js: `_hopsFuse = new Fuse(_allHops, { keys: ['name', 'description'], threshold: 0.35, minMatchCharLength: 2, ignoreLocation: true })`
   - Call `callback()` on success
   - On error: render error state to `#hops-catalog` with retry button (class `catalog-retry-btn`) that re-calls `loadHops(callback)`

8. **`buildHopFilters()`** — Derive flavor profile filter buttons from data:
   - For each `_hopGroups` entry, compute the dominant flavor of its first variant
   - Collect unique flavor labels that appear in the data
   - Sort alphabetically
   - Render filter buttons into `#hops-filter-row` using existing `.catalog-filter-btn` class
   - Each button click toggles its flavor in `_activeFlavorFilters` array and calls `renderHops()`
   - Active buttons get `active` class (per existing pattern)
   - Add an "All" button that clears all filters (always first button)

9. **`wireHopEvents()`** — Wire search and sort controls:
   - `#hops-search` input: debounced `renderHops()` call (180ms delay)
   - `#hops-sort` select: immediate `renderHops()` call on change

10. **`buildHopCard(group)`** — Build a complete hop card DOM element:
    - Outer div: classes `product-card hop-card`
    - Use first variant as the "default" display variant (smallest/cheapest)
    - **Collapsed section:**
      - `<h4>` with hop group name (`.textContent` -- never `.innerHTML` for Zoho data)
      - `.hop-alpha` span showing alpha acid: `"Alpha Acid: X%"` (read from `item.alpha_acid`, per D-03)
      - `.hop-flavor-tags` div with top 2-3 flavor tag spans (class `hop-flavor-tag`), derived via `getTopFlavorTags()`
      - `.product-detail-row` showing price of the default variant via `formatCurrency()`
    - **Accordion toggle** using `buildLabelNotesToggle` pattern (per D-08, D-12):
      - Outer `.notes-wrap` div
      - Button with class `notes-toggle`, text `"Hop Details"`, `aria-expanded="false"`, contains `<span class="chevron">&#9660;</span>`
      - Inner `.notes-body.hop-notes-body` div (two classes: `notes-body` for animation + `hop-notes-body` for max-height override)
      - Toggle click handler: `classList.toggle('open')`, update `aria-expanded`, call `trackEvent('detail', sku, name)` on open
    - **Expanded panel** (inside `.notes-body.hop-notes-body`):
      - `.hop-detail` container div (flex column, centered)
      - `.hop-radar-wrap` div containing `buildHopRadarChart(variant)` SVG -- OR `.hop-radar-placeholder` with text "Sensory data coming soon" if all 6 scores are 0
      - `.hop-specs` div: "Alpha Acid: X%" (per D-03)
      - `.hop-origin` paragraph: "Origin: {country}" (per D-04, from `item.origin`). If no origin data, omit.
      - `.hop-notes` paragraph: notes/history text (per D-05, from `item.description`). Use `.textContent`. If empty, omit.
      - **Size toggle** (per D-10, D-11): If group has 2+ variants, render `.hop-size-toggle-group` with `.hop-size-btn` buttons. Each button shows the size label (extracted from name suffix, e.g. "1 oz", "4 oz"). First button gets `active` class + `aria-pressed="true"`. Clicking a size button: updates active state on all buttons, updates `.hop-price` display, updates the cart product reference to the selected variant's SKU/price/name.
      - `.hop-price` span showing price of currently selected variant
      - `.product-reserve-wrap` div for cart control: build cart object with `_item_type: 'ingredient'` (per D-19). Call `hasWeightConfig(item)` to decide renderer: if true use `renderWeightControl`, if false use `renderReserveControl`. Set `._reserveProduct`, `._reserveKey`, `._reserveRenderer` on the wrap element.
    - Call `injectProductSchema(variant, 'ingredient')` for the default variant

11. **`renderHops()`** — Main render function:
    - Get search query from `#hops-search` value
    - Get sort value from `#hops-sort` value
    - Start with `_hopGroups` array
    - **Filter by flavor**: if `_activeFlavorFilters` is non-empty, keep groups where the dominant flavor of the first variant is in `_activeFlavorFilters` (OR logic)
    - **Filter by search**: if search query exists, use `_hopsFuse.search(query)` on `_allHops`, collect matching hop names, then filter `_hopGroups` to only those whose name matches a result
    - **Sort**: `name-asc` (alpha ascending on group name), `name-desc`, `alpha-desc` (by parseFloat of first variant's alpha_acid descending), `price-asc` (by first variant price ascending), `price-desc`
    - Clear `#hops-catalog` innerHTML
    - If filtered array is empty: render `.catalog-no-results` with text "No hops match your filters" and sub-text "Try adjusting the flavor profile or search term."
    - Otherwise: loop and call `buildHopCard(group)`, append to catalog
    - After render: call `equalizeCardHeights()` and `handleDeepLinkedItem()`
