<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| middleware → Apps Script (server_token) | Balance reads/writes cross here; only the server token authorizes them |
| concurrent HTTP → single Apps Script execution | Two redemptions for one cert can race within the execution window |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-04 | Tampering | Double redemption via race (negative balance) | mitigate | acquireScriptLock(15000) wraps every balance write; balance check + write inside one locked critical section (Pitfall 2) |
| T-44-05 | Repudiation | Replay of a successful redemption | mitigate | last_tx_ref idempotency: matching transaction_ref returns prior result without re-decrementing |
| T-44-06 | Elevation of privilege | Negative/over face_value or amount = free money | mitigate | amount ≤ balance+0.001 guard; issue face_value bounds enforced upstream (44-03); status must be 'active' |
| T-44-07 | Spoofing | Unauthorized call to balance actions | mitigate | All seven actions are server_token-gated (no Google OAuth path); void also requires staff context for the admin list |
| T-44-SC | Tampering | npm/pip/cargo installs | N/A | No package installs in this phase |
</threat_model>
