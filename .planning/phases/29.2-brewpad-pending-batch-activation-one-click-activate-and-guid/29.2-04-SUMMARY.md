# Phase 29.2 Plan 04: CR-01 Detail-Pane Activate Re-Render Fix Summary

One-liner: Fixed bare-object `renderBatchDetail(b)` call at brewpad.js:2611 to `renderBatchDetail(data)`, closing BLOCKER CR-01 — blank detail pane and corrupted module state after one-click Activate.

## What Was Built

Closed gap CR-01 (verification truth #8): the detail-pane Activate success handler at js/brewpad.js:2611 was calling `renderBatchDetail(b)` with a bare batch object, but `renderBatchDetail` expects `data = { batch, tasks, plato_readings }` and dereferences `data.batch` at line 2270. Passing the bare object caused `data.batch` to be `undefined`, rendering a blank pane and leaving `_detailBatchId = undefined` and `_currentBatchDetail = {}` for the rest of the session.

The fix: change line 2611 from `renderBatchDetail(b)` to `renderBatchDetail(data)`. The `data` parameter of the enclosing `renderBatchDetail` function is in closure scope at line 2611, and `data.batch === b` (the same in-memory object, already mutated to `status: 'primary'` at line 2599).
