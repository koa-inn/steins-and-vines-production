## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29.2-01 | Tampering | `start_date` injected via `update_batch` payload | accept | `start_date` is in the Apps Script `allowedFields` allowlist and passes server-side `sanitizeInput` (adminApi.gs:2164); client only sends `todayPacific()` output (YYYY-MM-DD) |
| T-29.2-02 | Tampering (XSS) | `b.batch_id` interpolated into the confirm-sheet message string | mitigate | `b.batch_id` is a server-issued `SV-B-NNNNNN` identifier; the confirm message is set as textContent by showConfirmSheet, not innerHTML — no script execution surface. No user-free-text is interpolated in this plan |
| T-29.2-03 | Tampering | Stale `expectedVersion` on pending activation overwrites a concurrent update | mitigate | Pass `expectedVersion: b.last_updated`; Apps Script optimistic lock rejects with `version_conflict` and the `.catch` surfaces "Failed: ..." toast |
| T-29.2-04 | Elevation of Privilege | Activation without auth | accept | Every `adminApiPost` carries the existing `accessToken`; Apps Script validates server-side — unchanged by this plan |
