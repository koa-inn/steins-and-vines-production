Close the BLOCKER gap CR-01 (verification truth #8): the detail-pane Activate success handler at js/brewpad.js:2611 calls renderBatchDetail(b) with a bare batch object, but renderBatchDetail expects data = { batch, tasks, plato_readings } and dereferences data.batch at line 2270. The fix is to call renderBatchDetail(data) — the data parameter of the enclosing renderBatchDetail function is in closure scope at line 2611, and data.batch === b (the same object, already mutated to status 'primary' at line 2599).

This is the single failed must-have for the phase goal.
