// Return a YYYY-MM-DD string for today (or today +/- N days) in Pacific time
function todayPacific(offsetDays) {
  var d = offsetDays ? new Date(Date.now() + offsetDays * 86400000) : new Date();

## Key Decisions for Planner

1. **`todayPacific` placement:** Place at file top-level (outside IIFE), immediately after `todayStr()` at line 16. Add to `module.exports` at line 5444.

2. **Sheet implementation:** Create `openScheduleActivateSheet` / `closeScheduleActivateSheet` / `buildScheduleActivateSheetHtml` as named functions inside the IIFE, modeled on `openCreateSheet` / `closeCreateSheet` at lines 3473–3499. The sheet element is created dynamically on first call (use `document.getElementById('bp-sa-sheet') || document.createElement(...)` pattern from `showConfirmSheet` at line 1751–1766).

3. **`_fermSchedules` guard in `openScheduleActivateSheet`:** Per Pitfall 4 in RESEARCH.md — check `_fermSchedules.length === 0` and call `reloadSchedules()` if empty before building the form.

4. **`expectedVersion` on Needs Scheduling rows:** Emit `data-version="' + escapeHTML(it.last_updated || '') + '"`. Empty string is safe (backend skips optimistic lock). If `last_updated` IS present in the summary object, it will be used; if not, the empty string degrades gracefully.

5. **Regression test must come first:** Per CLAUDE.md rule 3, write `tests/frontend/brewpad-activation.test.js` with the pending-guard regression test BEFORE touching the badge handler.
