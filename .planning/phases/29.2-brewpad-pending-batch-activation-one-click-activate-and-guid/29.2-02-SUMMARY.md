## What Was Built

**Needs Scheduling row markup** — The `pend.forEach` render loop (js/brewpad.js:1117-1139) now wraps all action buttons in a single `<div class="bp-task-actions">`:
1. **Activate** (`bp-needsched-activate-btn`) — carries `data-batch-id` and `data-version` (from `escapeHTML(it.last_updated || '')` — empty string safe per Pitfall 1 rationale)
2. **Schedule & Activate** (`bp-needsched-sa-btn`) — carries `data-batch-id`
3. **Delete** (`bp-needsched-delete-btn`) — existing button relocated into wrapper, attributes byte-for-byte identical

All interpolated fields (`batch_id`, `product_name`, `customer_name`, `last_updated`) pass through `escapeHTML(... || '')`.

**One-click Activate delegation** — `.bp-needsched-activate-btn` branch in the dashboard `dashInner` click handler:
- Reads `data-batch-id` and `data-version` from the button
- Calls `showConfirmSheet` with descriptive message
- On confirm: disables button, POSTs `update_batch` with `{ status: 'primary', start_date: todayPacific(), expectedVersion: ver }`
- On success: `showToast('Batch activated', 'success')` + full cache-bust (`_batchesLoaded=false; _allBatchesData=[]; _eagerLoadTime=0; _dashLoadTime=0`) + `loadDashboard()`
- On error: toast + re-enables button

**Schedule & Activate delegation** — `.bp-needsched-sa-btn` branch:
- Reads `data-batch-id` from button
- Loops `_allBatchesData` to find a cached full batch record
- If found: calls `openScheduleActivateSheet(batchRow)` immediately
- If not found: disables button, fetches via `adminApiGet('get_batch', ...)`, then calls `openScheduleActivateSheet((r.data && r.data.batch) || { batch_id: bid2 })` — error path re-enables button

**Markup-contract tests** — 5 new assertions appended to `tests/frontend/brewpad-activation.test.js` under `describe('needs scheduling activation markup', ...)`:
- Three class-name constant pins (`bp-needsched-activate-btn`, `bp-needsched-sa-btn`, `bp-needsched-delete-btn`)
- `todayPacific()` format pin (cross-plan start_date dependency from 29.2-01)
- `escapeHTML('<x>')` XSS guard pin
