## What Was Built

**todayPacific(offsetDays)** — a Pacific-timezone date helper placed at file top-level in `js/brewpad.js` (immediately after `todayStr()`, outside the IIFE). Returns `YYYY-MM-DD` via `toLocaleDateString('en-CA', { timeZone: 'America/Vancouver' })`. Accepts an optional `offsetDays` integer for relative date calculations. Exported via `module.exports` for unit testing.

**Regression test file** (`tests/frontend/brewpad-activation.test.js`) — written and committed before any source fix (CLAUDE.md rule 3). Contains:
- `describe('todayPacific')`: 3 tests confirming format and offset behavior (were RED before Task 2, GREEN after)
- `describe('pending status detection')`: 2 regression reference tests that document the exact silent-promotion bug (always pass — they test plain array math, not source exports)

**Status badge pending guard** — inserted as the FIRST statements inside the `statusBadge.addEventListener('click', ...)` handler at `js/brewpad.js:2503`. When `b.status === 'pending'`, the handler:
1. Opens an "Activate" confirm sheet with descriptive message
2. On confirm: POSTs `update_batch` with `status: 'primary'`, `start_date: todayPacific()`, and `expectedVersion: b.last_updated`
3. On success: updates badge DOM, shows "Batch activated" toast, calls `callSyncZoho`, updates both caches, resets load flags, re-renders list, removes sessionStorage entry
4. `return` after the pending branch — non-pending cycling logic is byte-for-byte unchanged
