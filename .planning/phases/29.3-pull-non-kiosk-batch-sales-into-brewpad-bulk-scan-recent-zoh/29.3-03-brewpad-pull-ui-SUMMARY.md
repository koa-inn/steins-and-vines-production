# Phase 29.3 Plan 03: BrewPad Pull from Zoho UI Summary

**One-liner:** Pull-from-Zoho confirm sheet wired to GET /api/batch/scan-invoices and POST /api/batch/bulk-create, with DRAFT badge, single-import field, per-row result toasts, and cache-bust list refresh.

## What Was Built

Staff can now trigger a "Pull from Zoho" sweep from the BrewPad filter bar. Clicking the button:

1. Opens a confirm sheet (`bp-pull-sheet`) using the existing `.bp-confirm-sheet` CSS overlay
2. Immediately fires `GET /api/batch/scan-invoices` (with `x-api-key`) to find ferment-in-store invoices not yet in BrewPad
3. Renders candidate rows — each with invoice number, customer name, kit items, and a DRAFT badge for `status==='draft'` invoices (D-05)
4. Each candidate has a pre-checked checkbox; staff can deselect any before creating
5. "Create Batches" fires `POST /api/batch/bulk-create` with `{ invoice_ids: [...] }` only (server-authoritative, D-06, T-29.3-09)
6. Uses `summarizeBulkResults` to pick `success`/`warn`/`error` toast level and surfaces `duplicate_so_number` in the warn path
7. After any successful creates, busts the client cache (`_batchesLoaded=false; _allBatchesData=[]; _batchesLoadTime=0; loadBatches()`) so the batch list refreshes
8. Single-import field validates via `isValidImportNumber` (`/^(INV|SO)-\d+$/i`, D-09) and fetches `scan-invoices?number=...`
