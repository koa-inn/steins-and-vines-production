## Blocking Issues (from 29.3-REVIEW.md — must resolve before production)

- [ ] **CR-01 (BLOCKER)** `apps-script/adminApi.gs:1910-1922` — `createBatch` dedup guard keys on `zoho_so_number` alone. A multi-kit invoice creates a batch for the first kit item, then every subsequent kit item on the same invoice returns `duplicate_so_number` and is silently dropped. Regresses the existing kiosk path. Fix: scope the guard to `zoho_so_number AND product_sku`.

SO-prefixed numbers also hit the wrong endpoint. Fix: use the two-step search-then-detail pattern already proven by `GET /api/batch/customer-by-number`.
- [ ] **WR-01 (warning)** `pos.js:1652-1664` — validate `invoice_ids` element format (numeric-ID regex) and cap batch size (~200) to prevent path-traversal-style abuse.
- [ ] **WR-02 (warning)** `js/brewpad.js:2283` — `_pullSheetBackdropHandler` added without a prior `removeEventListener` guard; accumulates on rapid re-opens.
