<objective>
Add the BrewPad UI for "Pull from Zoho": a control in the batch filter bar that scans recent
Zoho invoices, an always-on confirm sheet listing candidate invoices (with draft badges), a
single-invoice import field, the bulk-create call on confirm, and a list refresh afterward.

Purpose: Give staff a one-click way to sweep ferment-in-store sales invoiced directly in Zoho
into BrewPad as pending batches — confirm-gated so nothing is created silently.

Output: New control + confirm sheet + single-import in js/brewpad.js, CSS, rebuilt minified
bundle, and a Jest test for the pure helpers.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BrewPad UI → middleware /api/batch/* | Staff-triggered fetch carrying x-api-key; user-typed invoice number is untrusted input |
| Rendered candidate data → DOM | Zoho-sourced strings (customer_name, invoice_number) inserted into innerHTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29.3-09 | Tampering | bulk-create request body | mitigate | buildBulkCreatePayload sends invoice_ids only; the server re-resolves all batch data (D-06). UI cannot inject batch fields. |
| T-29.3-10 | Information Disclosure / XSS | candidate rows rendered to innerHTML | mitigate | escapeHTML() on every dynamic value (customer_name, invoice_number, kit names) before innerHTML — ES5 codebase rule. |
| T-29.3-11 | Spoofing | scan / bulk-create fetch | mitigate | All calls send x-api-key: mwApiKey(); server enforces 401 (plan 29.3-01). No new auth surface added client-side. |
| T-29.3-12 | Elevation/Abuse | accidental mass create | mitigate | Always-on confirm sheet (D-06); staff explicitly select+Create; draft badge (D-05) flags unfinalized invoices. |
| T-29.3-13 | Input validation | user-typed import number | mitigate | isValidImportNumber gates /^(INV|SO)-\d+$/i before any fetch; server re-validates (D-09). |
| T-29.3-SC | Tampering | npm installs | accept | No new dependencies; reuses existing brewpad helpers and build toolchain. |
</threat_model>
