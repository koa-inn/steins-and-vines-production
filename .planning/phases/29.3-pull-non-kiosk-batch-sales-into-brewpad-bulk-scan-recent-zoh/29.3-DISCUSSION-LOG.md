## Scan window & rate cap

| Option | Description | Selected |
|--------|-------------|----------|
| Last 30 days, paged cap | ~30-day window + hard page cap (~200 invoices); detail-fetch only invoices without cf_batch_status | ✓ |
| Last 7 days | Tighter window, fewer detail fetches; misses older un-batched sales | |
| Last 90 days | Wide net for first-run backlog; many more detail fetches, higher quota risk | |
| Last N invoices (count-based) | Bound by count rather than date; predictable call ceiling | |

**User's choice:** Last 30 days, paged cap (Recommended)
**Notes:** Hard cap is non-negotiable given prior Zoho quota exhaustion. `cf_batch_status` skip applies regardless of window.
