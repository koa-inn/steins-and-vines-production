## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tight badge padding |
| sm | 8px | Compact element spacing, search bar gap |
| md | 16px | Default element spacing, cart pane padding |
| lg | 24px | Button padding (12px 24px per existing .btn), section padding |
| xl | 32px | Layout gaps between major pane sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch targets: all tap targets maintain min-height 44px (iOS tap target minimum) — matches existing `.btn` and `.btn-secondary` which declare `min-height: 44px`
- Recipe prompt sale-type buttons: min-height 64px (large tap targets — staff makes this choice dozens of times per day; D-02 priority)
- Card body internal padding: 0.55rem 0.65rem 0.7rem — matches `.kiosk-product-body` exactly; recipe cards inherit this

## Color

All values from detected CSS custom properties in css/kiosk.css lines 15–62.

| Role | Token | Resolved Value | Usage |
|------|-------|----------------|-------|
| Dominant (60%) | `--cellar-canvas` | #e8e2ca | Page background, card placeholder fills |
| Secondary (30%) | `--cellar-raised` + `--cellar-surface` | #faf8f2 / #f5f1e6 | Card backgrounds, pane surfaces |
| Accent (10%) | `--barrel` | #77462d | Primary CTA buttons, price display, active borders, sale-type button selected state |
| Accent (secondary) | `--cellar-green` | #4a6f4b | Button hover/active states, in-store badge, all-ok availability dot |
| Destructive | `--batch-danger` | #a83232 | Out-of-stock state, error messages, cannot_brew availability |

Accent reserved for:
- Recipe card price text (`.kiosk-product-price` pattern)
- Primary CTA "Add to Cart" button (`.btn` background)
- Selected sale-type button border/fill
- Active card border on hover/tap
- "Ferment in Store" sale-type badge (matches `--cellar-green` from `.kiosk-type-badge--kit`)

Availability status dot colors (new component, follows existing badge pattern):
- `all_ok` dot: `--batch-success` (#3d7a40) — green
- `some_low` dot: `--batch-warning` (#b87a1a) — amber
- `cannot_brew` dot: `--batch-danger` (#a83232) — red
- `unknown` dot: `--ink-muted` (#b8a898) — grey

Type badge for recipes (follows `.kiosk-type-badge` pattern):
- Recipe badge: background `--cellar-green` (#4a6f4b), color #fff — matches `--kit` convention

## Layout Contract

### Kiosk Browse View — Recipe Mode

The existing `.kiosk-browse-layout` (grid: 1fr 340px) is preserved. Only the left `.kiosk-product-pane` content changes when recipe mode is active.

```
┌─────────────────────────────────────────┬──────────────────┐
│  [Products]  [Recipes]   ← mode toggle  │                  │
│─────────────────────────────────────────│   Cart (340px)   │
│  [Search recipes...] [Refresh]          │   (unchanged)    │
│─────────────────────────────────────────│                  │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐  │                  │
│  │Recipe│ │Recipe│ │Recipe│ │Recipe│  │                  │
│  │ card │ │ card │ │ card │ │ card │  │                  │
│  └──────┘ └──────┘ └──────┘ └──────┘  │                  │
└─────────────────────────────────────────┴──────────────────┘
```

### Recipe Card Layout (within `.kiosk-product-card`)

```
┌──────────────────────────────┐
│  [Recipe] badge   ● avail dot│  ← absolute positioned, top-right
│──────────────────────────────│
│  Recipe Name (2-line clamp)  │  ← .kiosk-product-name
│  Style · ABV%                │  ← .kiosk-product-sku (reused class)
│                              │
│  $XX.XX                      │  ← .kiosk-product-price
│  incl. brewing fee           │  ← .kiosk-product-makers-fee (reused)
│  ● all good / low / out      │  ← .kiosk-product-stock (--low / --out)
└──────────────────────────────┘
```

No product image section — recipe cards skip the `.kiosk-product-img` / `.kiosk-product-img-placeholder` block. Card min-height remains 180px.

## Interaction States

| Component | State | Visual Treatment |
|-----------|-------|-----------------|
| Recipe card | Default | `.kiosk-product-card` base |
| Recipe card | Hover | border-color `--barrel`, box-shadow 0 2px 8px rgba(119,70,45,0.12) |
| Recipe card | Active/tap | box-shadow inset 0 2px 8px rgba(0,0,0,0.15), border-color `--barrel` |
| Recipe card | Cannot brew | opacity 0.55 — matches `.kiosk-product-card--out-of-stock` |
| Recipe card | Unknown stock | Normal opacity — staff can still attempt (blocked at checkout) |
| Sale-type button | Unselected | `.btn-secondary` styles |
| Sale-type button | Selected | `.btn` styles (background `--stain`, color `--cellar-canvas`) |
| Sale-type button | Both unselected | "Add to Cart" button hidden |
| Sale-type button | One selected | "Add to Cart" button revealed with locked_price shown |
| Add to Cart | Tap | Adds all ingredient line items + fee(s) to kiosk cart; returns to products mode |
| Availability banner (some_low) | "Proceed anyway" tap | Banner dismisses; sale continues |
| Availability banner (cannot_brew / unknown) | No action available | Banner is display-only; checkout remains blocked |
| Mode toggle | Active mode | border-bottom 2px solid `--barrel`, font-weight 700, cursor: default |
| Mode toggle | Inactive mode | plain text, cursor: pointer, hover: color `--barrel` |
