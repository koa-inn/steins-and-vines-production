Zoho → Helcim Sync Plan

Pushing your ~50–200 products and customers from Zoho Inventory/Books into the Helcim POS app

1Two Ways to Sync Products

CSV Export → Helcim Import

Your middleware pulls the full product catalog from Zoho Inventory (it already does this), generates a CSV in Helcim's import format, and you upload it to Helcim manually or on a schedule.

✓ No Helcim API key needed — uses built-in import tool
✓ You can review the data before uploading
✓ SKU matching auto-updates existing products

△ Not real-time — you'd re-run when catalog changes

API Push (Automated)

Build a sync endpoint in your middleware that calls Helcim's Product and Customer APIs directly whenever Zoho catalog changes. Fully automated, no manual CSV step.

✓ Fully automatic — no manual uploads
✓ Can be triggered by cache refresh or cron

△ Helcim's Product API is less documented than their Payment/Customer API — may require testing
△ More code to build and maintain

2Product Field Mapping — Zoho → Helcim

Helcim CSV Column Your Zoho Field Notes
NAME name Direct map — product display name
SKU sku Key for matching — if SKU exists in Helcim, import updates it
PRICE rate Selling price from Zoho. Your middleware anchors this server-side already
CATEGORY custom_fields → "Type" Wine, Beer, Cider, Seltzer — maps to Helcim product categories
BRAND brand Fetched from item detail endpoint (bulk fetch)
DESCRIPTION description Sales description from Zoho
COST — Purchase price — available from Zoho if needed, not currently fetched
TRACK_INVENTORY true Set to true for all goods-type items
WEIGHT — Not relevant for wine/beer kits — leave blank or 0

4How the Sync Works

📦
Zoho Inventory (Source of Truth)
Your full product catalog with custom fields, pricing, stock levels, and customer contacts. Already fetched and cached by your middleware.
⚙️
Your Middleware (Transformer)
New endpoint: /api/admin/helcim-export — fetches products from cache, maps Zoho fields to Helcim's CSV columns, generates downloadable file. Same for customers.
📱
Helcim Import
Upload the CSV through Helcim's Product Import tool (in your Helcim dashboard). SKU matching automatically updates existing products and adds new ones.
💳
Helcim POS on iPad
Your iPad POS app now shows all your Zoho products with correct names, prices, categories, and stock levels. Ready to ring up sales.

5Implementation Options

Option A: Admin Endpoint + Manual Upload

Add a /api/admin/helcim-export endpoint that returns a CSV. You hit it when your catalog changes, download the file, and upload to Helcim's import page. Simple, low-risk, and you control when syncs happen.

Easy — a few hours of work

Option B: Scheduled Auto-Sync

A cron job in your middleware (you already have node-cron) that runs nightly or on product cache refresh. It generates the CSV and uploads it via Helcim's API automatically. Set-and-forget after initial setup.

Moderate — depends on Helcim API support

💡 Pro tip: Start with Option A

Build the CSV export endpoint first. This is useful on its own and gives you a working sync immediately. Later, you can automate it with a cron job once you've confirmed the data maps correctly and Helcim imports look good on the POS. Your middleware already has the csv-to-snapshot.js script pattern to follow, just in the other direction.

6What to Do First

1
Download Helcim's sample CSV templates
Go to your Helcim dashboard → Products → Import → download the Product Import and Customer Import sample CSVs. This gives you the exact column headers.
2
Build the export endpoint in your middleware
New route that reads from your product cache and outputs a CSV matching Helcim's format. Same for customer contacts from Zoho Books.
3
Test with a small batch first
Export 5–10 products, import into Helcim, and verify they show up correctly on your iPad POS with the right prices and categories.
4
Full sync + repeat when catalog changes
Once confirmed, export your full catalog and all customers. Re-run whenever you add products in Zoho — Helcim's SKU matching handles the rest.
